🚨 주의 (장애 이력 및 예방 지침)
- [과거 장애 1]: 가상환경(venv)을 활성화하지 않고 글로벌 python으로 uvicorn을 실행하여 `ModuleNotFoundError: No module named 'langgraph'`가 발생한 이력이 있습니다. 반드시 `.venv\Scripts\python.exe`를 사용하거나 가상환경을 활성화해야 합니다.
- [과거 장애 2]: `uvicorn main:app`을 직접 실행하면 포트가 8000으로 할당되어 프론트엔드(Vite)가 바라보고 있는 포트(8080)와 달라 연결이 거부되는 오류가 발생했습니다. 반드시 `run.py`를 통해 기동해야 올바른 포트(8080)와 인코딩(utf-8)이 적용됩니다.

-----------------------------------------------------------
▶ 1. 백엔드 (FastAPI) 기동 방법
-----------------------------------------------------------
1. 프로젝트 루트 경로(c:\\WorkSpace\\gemini_agent_team_verG)로 이동합니다.
2. 가상환경의 파이썬으로 `run.py`를 실행합니다.

명령어:
> venv\Scripts\python.exe run.py

(※ `run.py` 내부에서 8080 포트를 지정하고 UTF-8 인코딩을 처리한 후 `main:app`을 기동합니다.)

-----------------------------------------------------------
▶ 2. 프론트엔드 (React / Vite) 기동 방법
-----------------------------------------------------------
1. `frontend` 폴더로 이동합니다.
2. (최초 1회) npm 패키지들을 설치합니다.
3. Vite 개발 서버를 실행합니다.

명령어:
> cd frontend
> npm install
> npm run dev

(※ 프론트엔드 서버는 `http://localhost:5173`로 기동되며, 내부 통신은 `http://localhost:8080`을 통해 백엔드와 연결됩니다.)
