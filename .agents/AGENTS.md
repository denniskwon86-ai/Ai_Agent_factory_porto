# Global Communication Directive
- 앞으로 에이전트와 사용자의 모든 대화, 에이전트의 생각하는 과정(thought), 서브에이전트와의 통신을 포함한 중간의 모든 의사소통은 반드시 **한국어(Korean)**로 진행해야 합니다.
- 이 규칙은 프로젝트 내 모든 에이전트 동작에서 최우선으로 적용됩니다.

# Execution & File Modification Policy
- 사용자가 질문이나 지시를 내리면, 무조건 **수정 및 실행 계획을 먼저 텍스트나 기획안으로 답신**해야 합니다.
- 특히 소스 코드나 파일을 수정해야 하는 경우, "어떤 파일을 어떻게 수정할 것인지" 명확히 제시하고 **사용자의 승인(Approve)을 얻은 후에만 실제 파일 수정 툴을 가동**해야 합니다.
