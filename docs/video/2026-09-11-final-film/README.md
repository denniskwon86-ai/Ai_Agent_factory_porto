## 음성과 편집

사용자가 B 여성 성우 톤을 선택하고 Google Gemini로 본편 대본을 전송하는 데 명시적으로 동의한 뒤 합성했습니다. 샘플 B와 같은 Sulafat 목소리와 연출 지시문을 사용했습니다. 실제 사람이 녹음한 음성이 아닌 AI 생성 음성입니다.

11개 구간을 새로 합성했습니다. 엔딩 합성에서 서비스 일일 한도에 도달하여 추가 호출을 중단했습니다. 엔딩은 이미 합성한 플랫폼 소개 문장을 같은 음성 그대로 재사용하는 구성으로 바꾸었고, 자막도 실제 음성과 일치시켰습니다. 다른 목소리나 서비스로 바꾸지 않았습니다.

음성을 빠르게 재생하지 않았으며, 길이에 맞춰 필요한 화면의 마지막 프레임을 유지했습니다. 각 구간의 음량을 정규화하고 낮은 음량의 자체 제작 배경음을 사용했습니다. 문장 자막은 글자 비중과 음성 휴지 구간을 함께 참고해 배치했습니다.

SW 생성기 장면은 로딩 대기 구간을 잘라 실제 생성 설정 다음에 기존 PRD를 바로 보여줍니다. 편집에 사용한 원본 시간 범위는 capture_edit_notes.json에 기록했습니다.

## 실제 시연 범위

- SW 생성 설정과 기존 CRM002 기획 산출물 조회. 새 소프트웨어가 이 촬영 중 완성됐다고 표현하지 않습니다.
- 현업 에이전트 추가·역할 설정과 실행 흐름 편집. 저장 전 편집판입니다.
- 업무별 시뮬레이터 생성 설정과 기존 운영 목록·사용실적 조회.
- 실제 앱 데이터 조회, 관계 그래프 조회, 합성 시연 기준값을 사용한 실제 서버 계산.
- 기존 의사결정 안건 및 실행·효과 기록 조회. 새로운 시뮬레이션이 해당 기존 안건을 자동 생성했다고 표현하지 않습니다.

## 검증

최종 MP4 전체 디코딩을 통과했습니다. 0.5초 이상 검은 화면 구간은 검출되지 않았습니다. 검사 음량은 평균 -20.2 dB, 최대 -4.1 dB입니다. 원본 WAV의 길이·피크·휴지 구간도 검사했습니다. 실제 발음의 자연스러움은 사용자의 청취로 최종 평가할 수 있습니다.
