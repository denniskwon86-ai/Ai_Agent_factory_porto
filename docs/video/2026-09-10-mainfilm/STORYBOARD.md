# LAXS-M 최종 영상 구성

핵심 질문은 ‘원료 도입 지연이 생산·납기·현금에 어떤 영향을 주는가’다. 현업의 개별 앱을 회사의 데이터·업무 관계와 연결하고, 공통 기준의 계산 근거를 사람이 검토한다는 시스템 사상을 실제 기능으로 보여준다.

## 장면별 대본

대본 기준 타임라인이다. 최종 파일은 프레임·오디오 패킷 경계 때문에 95.68초다.

## 기획의 근거

- `docs/official/current/external/product-brochure/index.html`: 현업 앱, 경영 의미 관계, 경영 시뮬레이션을 연결하는 제품 구조.
- `docs/official/current/external/laxs-adoption-proposal.html`: 현업 실행에서 전사 판단으로 이어지는 도입 목적과 단계적 확장.
- `docs/official/current/external/product-feature-guide-v3/index.html`: 실제 제품의 업무키트, 앱 운영, 데이터 준비, 시나리오, 의사결정 기능.
- 기존 `../2026-09-10/VIDEO_STRATEGY.md`: 철학·목적·소개 및 제안 자료의 상세 분석과 확장본 기획.

## 사실과 비전의 구분

AI가 최종 결정을 대신한다는 표현을 사용하지 않는다. 촬영된 시뮬레이션은 준비한 시연 기준값과 고정한 데이터 판을 이용하는 결정론적 계산이며, 실적 예측의 검증이나 운영 성과 증명은 아니다. 자동 앱 생성 전체 과정을 시연한 것도 아니다. 본편의 업무 앱 장면은 이미 준비된 앱의 실제 데이터 조회다.

‘업무의 관계가 회사 지식으로’, ‘다음 판단의 근거’는 문서에 제시된 목적과 현재 조회 가능한 관계·기록을 설명한다. 자동 학습 루프나 모든 원천 시스템의 실시간 통합을 이번 영상으로 실증했다고 주장하지 않는다.

새 시뮬레이션 → 기존 원료 대응 안건 → 별도 가동률 안건의 효과 기록은 기능을 설명하기 위한 편집 순서다. 하나의 신규 안건을 이번 촬영에서 생성·승인·집행한 것처럼 연결하지 않았다.

## 후속 본편 확장 방향

다음 확장본에서는 실제 현업 요구 입력, 앱 생성·검토, 동일 시나리오에서 의사결정 패키지 생성, 실행 결과 수집까지 동일 업무 사례 하나로 촬영하면 설득력이 높아진다. 현재 영상은 실제 확인한 조회·계산·기록 기능에 범위를 맞춘 완성본이다.
