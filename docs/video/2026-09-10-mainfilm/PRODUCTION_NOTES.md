# LAXS-M 소개 본편 — 재제작 방향

2026-09-10 · 최종 본편 및 실제 기능 시연 영상 완료 · 기존 20초 샘플의 후속 작업

사용자 피드백: 이전 음성은 로봇처럼 부자연스럽고 화면도 기대에 미치지 못했다. 본편은 더 자연스럽고 부드러운 음성과 실제 기능 시연을 포함해야 한다.

## 이번 제작 기준

- 음성: Windows 기본 음성을 폐기하고 `ko-KR-SunHiNeural` 한국어 신경망 합성 음성 사용. 실제 성우 녹음으로 표시하지 않는다.
- 속도: -4%, 음높이 -2Hz. 원본 발화 길이를 보존하고 음성을 시간에 맞춰 억지로 압축하지 않는다.
- 대본: 문서식 명사 나열 대신 질문과 설명으로 이어지는 구어체. 9개 구간 약 95초.
- 화면: 인트로·브랜드 엔딩 외에는 현재 로컬 제품의 실제 브라우저 조작과 결과를 녹화한다. 정지 캡처에 움직임만 넣고 기능 시연이라 부르지 않는다.
- 기능 표현: 가정 입력·계산 실행·결과 확인은 실제 성공한 경로만 담는다. 화면을 조작하거나 응답을 가짜로 바꾸지 않는다.
- 시연과 실적: 시연 데이터임을 표시한다. 시연 수치를 실제 경영 성과로 설명하지 않는다.
- 행동 경계: 외부 발간·메시지·실제 업무 승인·데이터 인증을 대신 실행하지 않는다. 결정·보고 기능은 기존 항목의 조회를 중심으로 촬영한다.
- 보안: 촬영 서버는 `127.0.0.1` 전용이다. 설치본 설정은 제품 `run.py`와 같은 함수를 적용한다.

## 편집 구조

1. 질문: 원료 도입 지연이 생산·납기·현금에 만드는 영향.
2. 제품 정의: 현업의 실행과 경영의 판단을 하나의 흐름으로.
3. 실제 화면: 경영 홈과 결정할 일.
4. 실제 화면: 원료 도입 앱의 발주·선적 데이터 조회.
5. 실제 화면: 업무 온톨로지의 영향 관계.
6. 실제 화면: 시나리오 입력·실행·결과 비교.
7. 실제 화면: 의사결정 근거·대안·영향부서.
8. 실제 화면: 별도의 기존 안건에서 조건부 승인·실행 담당·기한·효과 기록 조회.
9. 엔딩: 현업이 만들고, 전사가 연결하며, 경영이 판단한다.

실제 화면 확인 후 대본을 수정하고 다시 녹음했다. 사용자가 로컬 계정 사용을 명시적으로 승인하여 촬영을 완료했다. 최종 산출물·검수 결과는 README.md를 참고한다.
