## 실제 촬영 범위

사용자가 승인한 기존 로컬 계정으로 정상 로그인한 세션을 사용했다. UI의 회사 문맥 선택에서 ‘제련공장 (시연 자료)’를 선택했다.

1. 경영 홈: 생산 단계 선택과 Twin 보조 정보 표시 전환.
2. 앱 운영: 원료 도입 앱을 열어 발주·선적 데이터를 실제 조회.
3. 업무 온톨로지: 관계 등록부의 ‘승인’ 조회 필터 적용 후 실제 노드 선택·전체 보기. 신규 관계를 승인한 것이 아니다.
4. 시뮬레이션: 인증된 판 7개를 선택하고 시연 기준값 및 가정을 직접 입력해 서버 계산 실행.
5. 의사결정: 기존 원료 도입 지연 대응 안건의 영향부서·의사결정자 검토서 조회.
6. 실행과 효과: 별도의 기존 가동률 조정 안건에서 조건부 승인 기록, 담당·기한 및 기록된 효과 조회.

본편 시뮬레이션과 기존 의사결정 안건은 동일 실행의 자동 후속 단계가 아니다. 대본에 ‘기존 안건’, 화면에 ‘기존 안건 조회’와 ‘기존 실행·효과 기록’을 표시해 구분했다.

## 데이터와 해석

제품 화면과 계산 응답은 실제 로컬 시스템에서 녹화했다. API 응답 대체, 결과 숫자 조작, 가짜 제품 UI는 사용하지 않았다. 시연 데이터와 직접 입력한 시연 기준값을 사용했으며 실제 회사 실적·예측 정확도·실증 ROI를 주장하지 않는다.

시연 기준값: 생산량 12,000ton, 기말재고 2,200ton, 구매지급 840억원, 기말현금 520억원, 영업이익 180억원, 전력비 72억원, 기간 30일.

변화 가정: 환율 +3.5%, 도입 지연 12일, 전력단가 +8%.

확인한 서버 결과: 생산량 7,200ton, 기말재고 7,000ton, 구매지급 869.4억원, 기말현금 414.544억원, 영업이익 103.944억원. 이 수치는 해당 시연 입력과 구현된 산식의 계산 결과이며 실제 경영 전망이 아니다.

## 편집과 검수

- 실제 녹화는 `captures/`에 보관. `capture_manifest.json`에 촬영 시작점과 조작 기록을 남겼다.
- 청록색 포인터와 가정 요약 상자는 촬영·편집용 강조 표시다. 제품 데이터나 기능을 대체하지 않는다.
- 원본 녹화의 필요한 부분을 잘라 확대했다. 장면 전환 외 실제 동작을 배속하지 않았다.
- 배경음은 외부 음원 없이 직접 합성한 조용한 화음이다. 말소리보다 낮게 배치했다.
- 최종 두 영상 전체 디코딩 성공, 0.5초 이상 검은 화면 없음. 음량 측정과 장면별 시각 검수를 수행했다. `verification.json` 및 각 `*_verification.txt` 참고.
- 최종 배포용은 `LAXS-M_mainfilm_final.mp4`다. `LAXS-M_mainfilm.mp4`는 배경음·최종 음량 정리 전의 편집 원본이다.

## 재현

`make_narration.py` → `capture_mainfilm.py` → `render_mainfilm.py` → `finish_outputs.py` 순서다. 촬영은 정상 로그인으로 만든 로컬 세션과 실행 중인 로컬 제품이 필요하다. 자격증명과 인증 세션은 이 문서 폴더에 포함하지 않는다.

소개 자료 분석과 확장본 기획은 [기존 VIDEO_STRATEGY.md](../2026-09-10/VIDEO_STRATEGY.md)에, 이번 실제 제작 범위는 [STORYBOARD.md](STORYBOARD.md)에 정리했다.
