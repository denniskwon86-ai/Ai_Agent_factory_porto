## 5. ★ 조심할 것 — 이 세션에서 실제로 데인 것

이 장이 이 문서에서 가장 값지다. **전부 실제로 일어난 일이다.**

### 5.1 좁은 범위로 시험을 돌리면 깨진 것을 못 본다

키트 관련 6 개 파일만 돌리면 전부 통과한다. `scripts/` 를 건드리는 시험 **전체**를
돌리자 셋이 나왔고, 그중 **둘은 분리(`a86a45295`) 때부터 깨져 있었다.** 그때
「합격조건 셋 통과」라고 보고한 것은 확인 범위를 넘어선 서술이었다.

    # 최소한 이 범위는 돌린다
    .venv/Scripts/python.exe -m pytest $(grep -rln 'kit_freeze\|starter_kit\|business_defs\|KIT-MFG' tests/ --include='*.py') -q -p no:warnings

⚠️ `--timeout` 같은 **없는 인자를 주면 pytest 가 exit 0 으로 죽는다.** 아무것도 안
  돌았는데 「통과」로 읽었다. 출력의 점(`....`)을 확인할 것.

### 5.2 ★ 작업 트리를 공유한다 — `git add <디렉터리>` 를 하지 말 것

`git add docs/` 를 했다가 **다른 세션이 작업 중이던 파일 다섯**(전사교육 PPT·PDF·
Codex 인계 문서)이 내 커밋에 딸려 갔다. 푸시 전에 잡아
`git reset <before> -- <paths>` 로 **작업 트리는 그대로 두고 인덱스만** 되돌렸다.

    git add <파일 하나하나>      # ✅
    git add docs/                # ✗ 남의 미커밋이 딸려 온다
    git status --porcelain       # 커밋 전 반드시

### 5.3 「지문 PASS」가 대장이 없어도 나왔다

`validate --version 1.1.0` 이 `frozen: true · fingerprint: PASS` 를 내는데 그 판본에
`.frozen` 도 `fingerprint.json` 도 없었다. **값을 바꿔도 검증 406 건이 통과했다.**
`is_frozen()`(manifest 상태로도 참) 과 `verify()`(대장 없으면 무검사 통과)가 만난
자리였다. 지금은 **`.frozen` 이 있는데 대장이 없으면 실패**한다.

### 5.4 우연한 일치가 결함을 가린다

`owner_of()` 는 사업 정의에 적힌 품목만 안다. 더미 품목은 기본값(마지막 사업)으로
떨어졌는데, **더미 완제품이 마침 전부 마지막 사업에 몰려 있어 우연히 맞았다.**
배정을 고르게 고치자 **판매 1,089 행이 마스터와 어긋났다.**

★ **하나를 고치면 그것이 가리고 있던 것이 드러난다.** 재고 음수 검사를 넣자 내가
  만든 것 말고도 **1.1.0 부터 있던 1,082 행**이 나왔다.

### 5.5 데이터를 고치면 지문이 바뀐다 — 판본을 새로 낸다

확정 판본은 **in-place 로 고치지 않는다.** 1.0.0 이 머지로 조용히 바뀐 사고가
있었고(`0ca2a58ad`), 그래서 **재생성이 아니라 파일과 지문이 판본을 보증한다.**

⚠️ 그 결과 1.0.0·1.1.0 은 **재생성되지 않는다.** 생성기 로직이 바뀌었기 때문이다.

### 5.6 안전장치를 우회하지 말 것

기초재고 창고를 고치며 넣은 폴백이 **「없는 창고면 멈춰라」를 조용히 무력화**했다.
`test_generator_must_stop_instead_of_falling_back` 이 잡았다. 못 찾으면 첫 후보를
그대로 돌려주고 **호출부가 검증해 멈추게** 해야 한다.

### 5.7 정본은 생성기다 — 산출물을 직접 고치지 말 것

`starter_kits/` 의 CSV 를 손으로 고치면 재생성에 덮어써진다. 고칠 것은
`scripts/business_defs/` 또는 생성기다.

## 8. 손대면 안 되는 것

| | |
|---|---|
| 확정 판본 (`.frozen` · `VALIDATED_*`) | **in-place 금지.** 새 판본으로 낸다 |
| `starter_kits/` 산출물 | 정본은 생성기다 |
| 다른 세션의 미커밋 변경 | 5.2 |
| 롱리스트(실재 회사)와 회사 프로파일(가상) | **섞지 않는다** |
| 개인 정보 | 대표자명을 CSV 에 저장하지 않는다. 최대주주가 개인이면 **「개인」**으로 적는다 |
| `DART_API_KEY` | 환경변수 또는 `engine/.env`(gitignore). **채팅에 붙이지 않는다** |
