# 외부 이직 준비 자료 패키지

> 목적: 사용자를 일반적인 DX 담당자나 AI 프로젝트 PM이 아니라, 제조업의 실제 경영 문제를 엔터프라이즈 AI 제품과 사업으로 전환할 수 있는 제품 리더로 포지셔닝한다.

## 작성 원칙

- 회사 소스, 실제 데이터, 내부 고유명사, 미공개 수치와 기밀을 사용하지 않는다.
- “혼자 시스템을 만들었다”가 아니라 문제 정의, 제품 사상, 의사결정, 팀 오케스트레이션, 위험 통제, 사업 확장 역량을 증명한다.
- 직함보다 제품 Mandate, 보고선, 팀, 예산, 데이터 접근, 사업권을 확인한다.
- 일반 SI 수행 PM, 자문만 하는 역할, 권한 없는 혁신 전담자는 목표에서 제외한다.

## 순차 작성 목록

| 순서 | 자료 | 사용 시점 | 핵심 질문 | 완료 기준 |
|---|---|---|---|---|
| CT-01 | 제품 리더 포지셔닝 문서 | 모든 자료의 기준 | 나는 누구이며 어떤 문제를 해결하는가 | 30초·90초·1페이지 설명 일치 |
| CT-02 | 비기밀 대표 사례서 | Hiring manager 대화 | 실제로 무엇을 구상·결정·완성했는가 | 문제·판단·구조·결과·교훈을 합성 사례로 설명 |
| CT-03 | Executive CV·LinkedIn 원문 | Recruiter 접점 | 경력이 목표 역할과 연결되는가 | 성과·제품·리더십 중심 2페이지 이내 |
| CT-04 | 목표회사·역할 Matrix | 시장 탐색 | 어디에서 가장 큰 권한을 얻는가 | 회사 10곳, 역할, Sponsor, 접점, 매력·위험 점수 |
| CT-05 | 제품 포트폴리오 Deck | 1차·2차 인터뷰 | 왜 이 사람이어야 하는가 | 12장 이내, 비기밀, 시각적 제품 증거 포함 |
| CT-06 | Leadership Story Bank | 행동면접 | 갈등·실패·결정에서 어떻게 행동했는가 | STAR 사례 8개와 검증 가능한 사실 |
| CT-07 | Role Mandate 제안서 | 최종면접·조건협상 | 입사 후 어떤 권한과 성과를 맡을 것인가 | 보고선·팀·예산·90일 성과·12개월 사업목표 |
| CT-08 | 접촉 메시지·대화 스크립트 | 소개·Recruiter 연락 | 어떻게 짧고 매력적으로 대화를 여는가 | 소개자·임원·Recruiter용 3종 |
| CT-09 | 회사·역할 Due Diligence | 인터뷰 병행 | 실제로 실행권이 있는 자리인가 | 권한·문화·데이터·예산·Sponsor·위험 검증 |
| CT-10 | Offer 비교·협상표 | 최종 의사결정 | 현재 조직보다 나은 선택인가 | 보상뿐 아니라 제품 통제권과 실행자원 비교 |
