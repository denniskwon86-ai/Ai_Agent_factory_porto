# 전선·케이블 3단 특성화 초안 — 두 번째 대상 (B)

- 기준일: 2026-09-16
- 대상: `소재제조 × 금속 × 비철금속 × **전선·케이블**` — **제련과 같은 키트, 3 단만 다름**
- 근거: 분류 스냅샷 `2026-09-11-2`(동결) · 키트 1.1.0 실측
- ⚠️ **도메인 검토 대상이다.** 아래 산업 서술은 일반 공개 지식으로 쓴 초안이고,
  **맞는지는 사람이 봐야 한다.** 근거가 파일에 있는 것만 「실측」으로 표시했다.

---

## 0. 왜 B 를 먼저 하나

`A(배터리소재) → 새 키트` 와 `B(전선) → 기존 키트의 3 단 확장` 중 **B 가 먼저**로
정해졌다([분류에서 업무키트로](TAXONOMY_TO_KIT_COVERAGE_2026-09-16.md) 4.5).

| | |
|---|---|
| 작고 빠르다 | 산업 정의를 새로 쓰지 않는다 — 같은 키트 안이다 |
| 분류가 깨끗하다 | `C2830` 이 곧 3 단이다. A 는 `C2820` 에 전지·양극재·황산니켈이 섞여 있어 **분류를 먼저 갈라야** 한다 |
| 밸류체인이 이어진다 | 제련의 산출물(전기동)이 전선의 투입물이다 |

⚠️ **B 를 해도 「새 키트를 만들 수 있는가」는 검증되지 않는다.** 그것은 A 의 몫이다.

## 1. 실측 — 지금 무엇이 있고 무엇이 없나

### 1.1 대상 (분류 스냅샷)

| | 회사 | 매출 |
|---|---|---|
| | 전선·케이블 3 단 전체 | **9 개사 · 10.7 조** |
| LS | 엘에스전선 | 4.2 조 |
| LS | 가온전선 | 1.4 조 |

같은 2 단(비철금속) 안의 이웃 — 제련·정련 11 개사 30.6 조 · 압연·압출 12 개사 3.9 조.

### 1.2 ⚠️ 키트에 전선 품목이 **하나도 없다**

`MDM-01` 을 열어 보면 전부 제련이다.

    동정광 · 니켈 MHP · 황산 98% · 동 매트 · 아노드동 · 전기동 · 고순도 황산니켈 …

13 번부터는 **더미**다(`공정소모품 013` · `포장재 014` · `중간재 016`). 즉 품목·BOM·
공정이 통째로 없다.

### 1.3 그런데 회사 프로파일은 이미 있다

`AFS-VIRTUAL-SUBSEA-CABLE-NA`(C2830 · 북미 해저케이블 생산법인안)의 가정이다.

```json
{"annual_capacity_km": 1800, "copper_price_change_pct": 10.0,
 "capex_krw_billion": 820.0, "local_content_pct": 55.0,
 "order_backlog_krw_billion": 1400.0}
```

★ 여기에 이미 **전선 사업의 지표 셋**이 들어 있다 — **길이(km)** · **수주 잔고** ·
**현지화율**. 제련에는 없는 것들이다.

다만 이것은 **투자 의사결정 시나리오**이지 그 사업의 일상 업무가 아니다.
`recommended_apps` 도 7 개 중 3 개뿐이다(APP-01·03·04).

## 2. 전선은 제련과 무엇이 다른가

⚠️ **여기부터는 도메인 서술이다.** 일반 지식으로 쓴 초안이고 검토가 필요하다.

### 2.1 ★ 구조는 닮았는데 **같은 것은 아니다**

| | 제련 | 전선 |
|---|---|---|
| 무엇을 사나 | 정광(금속 함유 광석) | **전기동 로드**(8mm) · 알루미늄 |
| 가격 위험 | LME 를 헤지로 중립화 | **고객에게 전가**(pass-through) |
| 어디서 버나 | **TC/RC**(제련수수료) + 회수율 + 부산물 | **가공비**(도체 가공 마진) |

둘 다 「**금속 가격은 통과시키고 가공 대가로 번다**」는 구조다.

★★★ **그렇다고 드라이버를 공유하면 안 된다.** TC/RC 는 **연 단위 벤치마크 협상**으로
정해지고 광산 공급과 제련 능력의 수급으로 움직인다. 전선 가공비는 **원가 + 마진**이고
수주 경쟁과 전력 투자 사이클로 움직인다. **움직이는 이유가 다르면 다른 동인이다.**

(이것이 [확산 분석](DIFFUSION_READINESS_ANALYSIS_2026-09-16.md) 4.3 이 금지하는
지점이다 — 구조가 닮았다는 것은 **가장 속기 쉬운 신호**다.)

### 2.2 전선에만 있는 것

| | 무엇 | 왜 제련에 없나 |
|---|---|---|
| **길이** | km · m 로 센다 (`annual_capacity_km` 이 그 증거) | 제련은 톤이다. **단위 체계가 다르다** |
| **도체 단면적** | `sq mm` 가 제품 규격의 핵심 | |
| **전압 등급** | 저압 · 고압 · 초고압 · HVDC | |
| **수주 잔고** | 해저·초고압은 **프로젝트 수주**다 (`order_backlog` 가 그 증거) | 제련은 연간 계약 물량 |
| **드럼·릴** | 출하 단위가 드럼이다 | |
| **인증** | KS · IEC · UL — 규격별 형식 승인 | |

### 2.3 공정이 다르다

    제련   정광 → 배소·용련 → 매트 → 전해정련 → 전기동
    전선   전기동 로드 → 신선 → 연선 → 절연 → 케이블링 → 시스 → (해저: 아머링)

**BOM 의 성격이 다르다.** 제련은 「함유 금속 대비 회수」(수율이 1 미만)이고, 전선은
「도체 중량 + 절연재」로 **무게가 늘어난다.**

## 3. 무엇을 더해야 하나 (초안)

### 3.1 산업 정의 — 품목·BOM·공정

[분류에서 업무키트로](TAXONOMY_TO_KIT_COVERAGE_2026-09-16.md) 3.2 의 **213 줄**에
해당하는 부분이다. 3 단 확장이므로 **기존 제련 정의에 더한다.**

| | 품목(초안) |
|---|---|
| 원료 | 전기동 로드 8mm · 알루미늄 로드 · XLPE · PVC · 시스용 PE · 차폐 동테이프 |
| 중간재 | 소선 · 연선 도체 · 절연 코어 |
| 완제품 | 고압 전력케이블 · HVDC 해저케이블 · 권선(Magnet wire) |

★ **전기동이 이미 키트에 있다**(`FG-CATHODE`). 제련의 산출물이 전선의 투입물이 되는
**밸류체인 연결을 한 키트 안에서 보여 줄 수 있다** — 이것이 B 의 고유한 값이다.

### 3.2 드라이버 (초안 — 검토 필요)

| ID | 이름 | 왜 기존 12 개로 안 되나 |
|---|---|---|
| `DRV-CU-PASSTHROUGH` | 동가격 전가율 | `DRV-COMMODITY` 는 **가격**이고 이것은 **전가되는 비율**이다. 전가율이 낮으면 구리가 올라도 못 받는다 |
| `DRV-PROCESSING-MARGIN` | 가공비(롤마진) | 전선사 수익의 본체. 제련의 TC/RC 에 대응하지만 **다른 것**이다(2.1) |
| `DRV-ORDER-BACKLOG` | 수주 잔고 | 프로젝트 사업의 선행지표. `DRV-DEMAND`(수요 변화)와 다르다 — **이미 확정된 물량**이다 |
| `DRV-CABLE-CAPACITY` | 생산 능력(km/년) | `DRV-DOWNTIME` 과 다르다 — 라인별 길이 기준 능력이다 |

⚠️ 넷 다 **초안**이다. 특히 전가율과 가공비가 **별개 동인인지 하나인지**는 도메인
판단이다.

### 3.3 필드 확장 (초안)

층 표기는 [필드 계층 설계](FIELD_LAYER_DESIGN_2026-09-16.md) 3 장을 따른다 —
`B:금속>비철금속>전선·케이블`.

| 데이터셋 | 필드 | 비고 |
|---|---|---|
| `MDM-01` | `conductor_size_sqmm` · `voltage_class` | 제품 규격 |
| `PRC-01` | `copper_settlement_rule` | 동 정산 방식(전가 조건) |
| `SLS-01` | `cable_length_km` · `drum_no` · `project_id` | 길이·출하단위·프로젝트 |
| `MFG-02` | `drawing_ratio` · `insulation_thickness_mm` | 공정 |

⚠️ **기존 필드로 되는지 먼저 본다**(확산 분석 2.4 의 교훈 — 제련에서 `byproduct_flag`
가 이미 있는 것과 겹쳤다). `quantity_uom` 이 이미 있으므로 **길이 단위는 필드를
더하지 않고 값으로 될 수 있다.**

## 4. ★★★ 확인했다 — **프로젝트 수주가 35 종에 없다**

초안을 쓰면서 「확인하지 않았다」고 적었던 것을 바로 확인했다. 35 종 계약의 필드
359 개를 전부 뒤졌다.

| 찾은 말 | 결과 |
|---|---|
| `project` · `backlog` · `progress` · `completion` · `wbs` | **하나도 없다** |
| `milestone` | `LOG-03.milestone_id` — **선적** 마일스톤이지 프로젝트 공정이 아니다 |
| `contract_id` | `PRC-01` · `PRC-02` — **구매** 계약뿐이다 |

### 4.1 판매 쪽이 비대칭이다

    구매   PRC-01 계약  →  PRC-02 발주        2단
    판매   SLS-01 수주·출하                   1단 — **계약이 없다**

`SLS-01` 은 `SO-000001-10` 같은 **개별 주문 한 줄**이다. 여러 출하를 한 프로젝트로
묶을 자리도, 공정률로 매출을 인식할 자리도 없다.

| 무엇 | 지금 되나 |
|---|---|
| 단순 수주잔고 (`order_quantity − shipped_quantity`) | ✅ 계산된다 |
| **프로젝트 단위 묶음** | ✗ |
| **진행기준(공정률) 매출** | ✗ — `FIN-03` 에도 자리가 없다 |

### 4.2 그래서 B 의 크기가 갈린다

| 전선 중에서 | 지금 구조로 |
|---|---|
| 권선 · 일반 전력케이블 — **반복 주문** | ✅ `SLS-01` 로 된다 |
| **해저케이블 · 초고압 — 프로젝트 수주** | ✗ 담을 자리가 없다 |

★ 하필 **LS전선의 성장 축(해저케이블)이 표현되지 않는다.** 키트에 이미 있는
`AFS-VIRTUAL-SUBSEA-CABLE-NA` 프로파일의 `order_backlog_krw_billion: 1400` 도
**프로파일 안의 가정일 뿐 데이터셋으로 내려오지 못한다.**

### 4.3 ⚠️ 이것은 전선만의 문제가 아니다

**수주형 사업 전체가 같다.** 16 칸 후보 중 「시공·건설」(144 개사 24 조)도, 조선·플랜트도
프로젝트가 업무의 중심이다. 확산 분석 3.2 의 커버리지 계산은 **데이터셋이 서는가**만
셌고 **수주 개념 부재는 세지 않았다** — 시공·건설 21/35 는 그만큼 낙관적인 수치다.
