## 2. 빠진 것 — 제련은 「금속을 파는 사업」이 아니다

현재 드라이버 12 개는 **범용 제조업**의 것이다. `DRV-COMMODITY`(LME 가격)가 있지만,
제련사는 금속 가격 자체로 벌지 않는다. **가격은 헤지로 중립화하고, 제련수수료와
회수율과 부산물로 번다.** 여기가 특성화 지점이고, 지금 그것이 비어 있다.

### 2.1 추가할 드라이버 다섯

| ID | 이름 | 왜 필요한가 |
|---|---|---|
| `DRV-TCRC` | 제련수수료(TC/RC) | **제련사 수익의 본체.** 정광을 사서 금속을 돌려주고 받는 수수료로, 연 단위 벤치마크 협상으로 정해진다. 광산 공급이 늘면 오르고 제련 능력이 늘면 내린다 |
| `DRV-RECOVERY` | 금속 회수율 | 정광에 든 금속 중 실제로 뽑아내는 비율. 1%p 차이가 손익을 가른다 |
| `DRV-GRADE` | 정광 품위 | 산지·광체별로 다르고, 품위가 낮으면 같은 톤수로 금속이 덜 나온다 |
| `DRV-BYPRODUCT` | 부산물 크레딧 | 황산·금·은. 동 제련에서 부수입이 아니라 **손익 구조의 일부**다 |
| `DRV-PREMIUM` | 지역 프리미엄 | LME 위에 얹히는 현물 프리미엄. 지역·형태(잉곳/캐소드)별로 다르다 |

기존 `DRV-YIELD`(수율)는 생산 수율이고 `DRV-RECOVERY`(금속 회수율)와 다르다 —
전자는 「투입 대비 산출량」, 후자는 「함유 금속 대비 회수 금속」이다. 합치면 안 된다.

### 2.2 데이터셋에 붙일 필드

기존 35 개 데이터셋의 **키는 바꾸지 않고 필드만 더한다**(`business_kits.py` 원칙).

| 데이터셋 | 추가 필드 | 비고 |
|---|---|---|
| `MDM-01` 품목·원료 | `metal_content_pct` · `concentrate_grade` · `payable_metal_pct` | 정광은 「톤」이 아니라 「함유 금속량」으로 거래된다 |
| `PRC-01` 구매계약 | `tc_usd_per_dmt` · `rc_cent_per_lb` · `qp_rule` · `assay_settlement_terms` | QP(Quotational Period)가 가격 확정 시점을 정한다 |
| `MFG-02` 생산실적 | `recovery_rate_by_metal` · `slag_loss_pct` | 금속별로 따로 잡아야 한다 |
| `SLS-01` 판매 | `byproduct_flag` · `premium_usd_per_ton` | 황산·귀금속 매출을 본제품과 갈라야 손익 구조가 보인다 |
| `EXT-02` 기준가격 | TC/RC 벤치마크 시계열 · 황산 가격 · 지역 프리미엄 | 지금은 LME 만 있다 |
| `MFG-03` 가동·정비 | `shutdown_type`(정기/돌발) · `planned_duration_days` | 정기보수는 연 단위 계획 사건이라 돌발 고장과 성격이 다르다 |

### 2.3 시나리오 넷

기존 `SCN-01`(환율 10% 상승) 형식 — driver × 변화량 × 영향지표 — 을 그대로 쓴다.

| 시나리오 | driver | 변화 | 영향 지표 |
|---|---|---|---|
| TC/RC 벤치마크 하락 | `DRV-TCRC` | −20% | `GROSS_MARGIN`, `CASH` |
| 정광 품위 저하 | `DRV-GRADE` | −1%p | `PRODUCTION_VOLUME`, `PURCHASE_COST` |
| 황산 가격 급락 | `DRV-BYPRODUCT` | −40% | `GROSS_MARGIN` |
| 정기보수 연장 | `DRV-DOWNTIME` | +14 일 | `PRODUCTION_VOLUME`, `GROSS_MARGIN`, `CASH` |

## 3. 고쳐야 할 것 — `industry_code` 가 틀렸다 (1.1.0 에서 반영)

`company_profiles/AFS-VIRTUAL-GLOBAL-SMELTING.json` 이 이렇게 되어 있다.

```json
"industry_code": "C2412",
"industry_name": "비철금속 제련·정련",
```

**KSIC 10 차에서 `C2412` 는 제강업(철강)이다.** 비철금속 제련·정련은 **`C2421`** 이다.
이름은 맞고 코드가 틀렸다. 우리 분류 데이터에서 LS엠앤엠·고려아연·SNNC 가 전부
`C2421` 로 신고돼 있으므로, 이 코드로는 롱리스트와 이어지지 않는다.

```
C2411 제철업 · C2412 제강업 · C2413 철강관
C2421 비철금속 제련·정련·합금   ← 여기다
C2422 비철금속 압연·압출·연신
```

`manifest.json` 의 `industry_codes: ["C24"]` 는 맞다(1 차 금속 제조업). 다만 제련
특화 판본에서는 **`["C2421"]`** 로 좁히는 편이 대상 매칭에 정확하다.

### ⚠️ 정본은 생성기다 — 산출물을 직접 고치면 덮어써진다

`company_profiles/*.json` 과 `samples/**/*.csv` 는 **`scripts/generate_sample_company_starter_kit.py`
가 만드는 산출물**이다. 프로파일 JSON 을 직접 고쳤더니 재생성 한 번에 되돌아갔다.
`industry_code` 도 생성기 안에 하드코딩돼 있어 거기를 고쳐야 한다.

### ⚠️ Excel 재계산에는 LibreOffice 가 필요하다

README 의 4 단계(`recalculate_sample_company_excel_templates.ps1`)가 `soffice.com` 을
찾는다. 없는 환경에서 1·3 단계만 돌리면 **수식 셀이 빈 채로 남아** Excel 검증이 깨진다
(`SIM-02:...:B4=None`). LibreOffice 가 없으면 `templates/excel/` 은 건드리지 말고
CSV·프로파일만 재생성한 뒤 Excel 을 원래대로 되돌려야 한다.

## 4. 적용 대상 — 롱리스트와 회사 프로파일은 다른 것이다

**둘을 섞으면 안 된다.**

- **회사 프로파일**(`AFS-VIRTUAL-*`)은 **가상 회사**다. `entity_mode: VIRTUAL`,
  `data_class: SYNTHETIC`, `not_for_management_decision: true`. 제품을 체험시키는 무대다.
- **롱리스트**는 **실재 회사**다. 이 키트를 누구에게 적용할 것인가의 명단이다.

실재 회사를 회사 프로파일로 만들면 합성 데이터에 실명이 붙어 「그 회사의 숫자」처럼
읽힌다. 그것이 `kit_registry.py` 가 경계하는 «없는 숫자로 경영 판단» 이다.

### 적용 대상 11 개사 (매출 1,000 억 이상)

| 회사 / 부문 | 매출 | 계열 | 갈래 |
|---|---|---|---|
| 엘에스엠앤엠 | 14조 3,600억 | LS | 1차 제련 |
| 고려아연 | 10조 5,300억 | 영풍 | 1차 제련 |
| 세아엠앤에스 | 1조 9,900억 | 세아 | 합금철 |
| **영풍 · 제련부문** | 1조 100억 | 영풍 | 1차 제련 |
| 에스엔엔씨 | 7,700억 | 포스코 | 1차 제련 |
| 토리컴 | 5,900억 | LS | 재자원화 |
| 지알엠 | 4,300억 | LS | 확인 필요 |
| 한국미래소재 | 3,800억 | LS | 확인 필요 |
| 한주라이트메탈 | 2,600억 | — | 확인 필요 |
| 스틸싸이클에스씨 | 1,700억 | 영풍 | 재자원화 |
| 포스코에이치와이클린메탈 | 1,400억 | 포스코 | 재자원화 |

- **영풍은 법인이 아니라 제련부문이다.** 법인 전체를 담으면 제련(1.0 조)보다 큰
  PCB부문(2.0 조)이 딸려 온다.
- **계열이 셋에 몰려 있다** — LS 4 · 영풍 3 · 포스코 2 로 11 곳 중 9 곳.
- 1,000 억 미만 4 건(에코프로씨엔지 · 스틸싸이클 · 에이치브이엠 · 에너지머티리얼즈)은
  폐배터리 재자원화라 성장 곡선이 달라 **관찰 대상**으로 둔다.
- 명단 근거는 KSIC 신고이고 법인 판정 오판정률은 표본 검증 **약 3%** 다 —
  접촉 전 사업 내용 확인이 필요하다.

### 재자원화는 같은 키트로 덮이지 않을 수 있다

1 차 제련(정광 → 금속)과 재자원화(스크랩·폐배터리 → 금속)는 **원료 조달 구조가 다르다.**
전자는 광산과 연 단위 TC/RC 를 협상하고, 후자는 불안정한 스크랩 수급과 회수율이 관건이다.
`AFS-VIRTUAL-CIRCULAR-METALS` 프로파일이 이미 있으므로, **한 패키지 안의 두 프로파일**로
가르는 편이 자연스럽다.
