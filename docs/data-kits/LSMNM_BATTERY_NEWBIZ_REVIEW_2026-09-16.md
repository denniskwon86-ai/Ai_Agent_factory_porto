# LS MnM 배터리소재 사업부 — 신규 사업의 업무키트를 어떻게 반영하나

- 기준일: 2026-09-16
- 물음: **신규 사업부라 매출 실적이 없어 공시자료에 내용이 없다.** 그런 대상에
  업무키트를 어떻게 줄 것인가
- ⚠️ 도메인 서술은 공개 지식으로 쓴 초안이다. 파일에서 확인한 것만 「실측」으로 적었다

---

## 0. 결론부터

**새 키트를 만들 필요가 없다 — 황산니켈 제조는 이미 키트 안에 완비돼 있다.**
없는 것은 산업이 아니라 **「신규 사업」이라는 상태**다.

그리고 분류가 이 사업부를 못 잡는 것은 **문제가 아니다.** 분류는 모르는 대상을
찾는 도구이고, LS MnM 은 이미 아는 대상이다.

---

## 1. 실측 — 황산니켈은 이미 키트에 있다

| 무엇 | 키트 안에 |
|---|---|
| 원료 | `RM-MHP`(니켈 MHP) · `RM-H2SO4`(황산 98%) · `RM-LIME`(소석회) |
| 중간재 | `WIP-NISO4`(조황산니켈 용액) |
| 완제품 | `FG-NISO4`(고순도 황산니켈) · `FG-LIOH`(배터리급 수산화리튬) |
| **BOM** | `FG-NISO4 ← MHP 1.15 + H2SO4 0.32 + LIME 0.08`, **수율 0.94** |
| 공장 | `plant-afs-battery-02`(제2공장) · 창고 `LOC-P2-RAW`·`LOC-P2-FG` |
| **생산 실적** | `MFG-02` 에 **267 배치**(full) · 108 배치(quick) |
| 외부 지표 | `NICKEL`(USD/TON) · `NICKEL_SULFATE` |
| 회사 프로파일 | `AFS-VIRTUAL-BATTERY-EXPANSION-2030`(제3공장 증설안) |

★ **「분류에서 업무키트로」 4.5 에서 A 를 「새 키트」로 분류한 것은 판정 기준의
이야기였다.** 실제 키트에는 이미 들어 있다 — 켐코(별도 법인)는 `C2820` 으로 가지만,
LS MnM 의 황산니켈은 **같은 법인 안의 사업**이라 제련 키트에 함께 담겼다.

⚠️ 여기서 드러나는 것: **같은 사업인데 법인 구조에 따라 분류가 달라진다.** 별도
법인이면 「부품제조 × 전자·정밀」, 사업부면 모법인을 따라 「소재제조 × 금속」이다.

---

## 2. 없는 것 — 「신규 사업」이라는 상태

### 2.1 실측: 램프업이 없다

`MFG-02` 의 36 개월 수율을 월별로 봤다.

    2023-08  0.9406      2026-06  0.9434
    2023-09  0.9318      2026-07  0.9454
    첫 6개월 평균 0.9378 · 마지막 6개월 평균 0.9452

**거의 평평하다.** 변동은 ±0.01 수준의 노이즈이고 **초기에 낮았다가 오르는 곡선이
없다.** 즉 지금 데이터는 **이미 안정 운영 중인 공장**을 그린다.

### 2.2 신규 사업은 무엇이 다른가 (초안 — 검토 필요)

| | 신규 사업에서 | 지금 데이터 |
|---|---|---|
| **수율** | 초기 낮음 → 12~24 개월 램프업 | 처음부터 0.94 |
| **고객 인증** | 샘플 → 파일럿 → 양산 승인. **승인 전에는 매출이 없다** | 없는 개념 |
| **가동률** | 초기 저가동, 단계적 상승 | 안정 |
| **원료 조달** | 장기계약 전이라 스팟 비중이 높다 | 계약 기반 |
| **손익** | 감가상각·초기 비용으로 적자 구간 | 정상 마진 |
| **판단 근거** | 실적이 없으니 **계획·시나리오가 유일** | 실적 36 개월 |

★ 마지막 줄이 핵심이다. **실적이 없는 사업일수록 참조 모델의 값이 크다** — 자기
데이터로 비교할 대상이 없기 때문이다.

---

## 3. 분류의 사각지대 — 그리고 그것이 문제가 아닌 이유

### 3.1 신규 사업은 분류에 안 보인다

    엘에스엠앤엠(주)   단위=법인   3단=제련·정련      ← 배터리소재 사업부가 안 보인다

이유가 둘이다.

| | |
|---|---|
| **실적이 없다** | 롱리스트는 매출 1,000 억 이상으로 거른다 |
| **사업부다** | 부문 공시가 있어야 세그먼트로 갈리는데, 실적이 없으면 공시에 없다 |

### 3.2 ★ 그런데 그것이 문제가 아니다

**분류는 「모르는 대상을 찾는 도구」다.** 시장에 어느 셀에 몇 개사가 있는지 보는
것이고, 그래서 매출·KSIC 같은 공시 데이터를 쓴다.

LS MnM 은 **이미 아는 대상**이다. 찾을 필요가 없다.

★ 즉 **분류와 키트가 1:1 이 아니다.**

| | 분류(롱리스트) | 키트 |
|---|---|---|
| 무엇 | 시장 전체에서 **대상 후보를 찾는다** | 정해진 대상에 **업무를 준다** |
| 신규 사업 | 안 보인다 | **줄 수 있다** |

⚠️ 다만 **일반화하면 한계가 남는다** — 「신규 사업을 하는 회사」를 시장에서 찾으려면
매출로는 안 되고 투자·증설 공시 같은 다른 신호가 필요하다. 그것은 분류 체계의
확장 과제이고 이 검토의 범위가 아니다.

---

## 4. 그래서 무엇을 하나 — 추천

**새 산업 정의도 새 키트도 필요 없다. 「신규 사업 회사 프로파일」을 더한다.**

### 4.1 왜 프로파일인가

키트는 이미 증설 시나리오를 프로파일로 다룬다 —
`AFS-VIRTUAL-BATTERY-EXPANSION-2030`(`capacity_increase_pct: 35` ·
`capex_krw_billion: 180`). **신규 사업도 같은 자리에 들어간다.**

| 후보 | 크기 | 판단 |
|---|---|---|
| 새 키트를 만든다 | 크다 | ✗ 황산니켈이 이미 있다(1 장) |
| 산업 정의를 더한다 | 중간 | ✗ 품목·BOM·공정이 이미 있다 |
| **회사 프로파일을 더한다** | **작다** | ✅ **추천** |

### 4.2 프로파일에 담을 것 (초안)

```json
{
  "company_profile_id": "AFS-VIRTUAL-BATTERY-NEWBIZ",
  "profile_role": "VIRTUAL_NEW_BUSINESS",
  "industry_name": "배터리소재 — 신규 사업 단계",
  "purpose": "실적이 없는 신규 사업부가 램프업·고객인증·초기손익을 사전 검증",
  "default_assumptions": {
    "ramp_up_months": 18,
    "initial_yield": 0.85,
    "target_yield": 0.94,
    "qualification_months": 12,
    "initial_utilization_pct": 40.0,
    "spot_purchase_ratio_pct": 70.0
  }
}
```

### 4.3 ⚠️ 그런데 가정값만으로는 부족하다

프로파일의 `default_assumptions` 는 **시나리오 입력**이지 데이터가 아니다. 실제
`MFG-02` 시계열은 여전히 평평한 0.94 다.

「우리 상황과 비슷하네」가 되려면 **생성 로직이 램프업을 그려야** 한다.

| | 무엇 | 크기 |
|---|---|---|
| ⓐ 프로파일 가정만 | 시나리오에서만 램프업을 다룬다 | 작다 |
| **ⓑ 생성 로직에 반영** | `MFG-02` 수율이 실제로 0.85 → 0.94 로 오른다 | **중간 — 추천** |

**ⓑ를 추천한다.** 신규 사업 담당자가 데이터를 열었을 때 **평평한 0.94** 를 보면
「우리 얘기가 아니다」가 된다. 그것이 경계(확산 분석 2.0)가 말한 「최소한의 도메인
이해가 반영된 채로 제공되어 적응이 빠르다」의 반대다.

ⓑ는 산업 정의가 아니라 **프로파일별 생성 파라미터**다 — `BusinessDef`(무엇을
만드나)와 다른 자리이고, 같은 산업에 여러 단계를 그릴 수 있게 한다.

## 5. 정리 — 세 층이 각각 무엇을 맡나

| 층 | 무엇 | 배터리소재에서 |
|---|---|---|
| `BusinessDef` (사업 정의) | 무엇을 만드나 | **이미 있다** — `business_defs/battery_materials.py` (2026-09-17 분리) |
| `FieldExtension` (필드 확장) | 그 산업에만 있는 열 | 검토 필요 — MHP 품위? 양극재사 규격? |
| **회사 프로파일 + 생성 파라미터** | **어떤 단계인가** | **여기가 빠졌다** — 램프업·인증·초기손익 |

★ 이번 검토로 세 번째 자리가 드러났다. 산업이 같아도 **사업 단계가 다르면 데이터가
달라야 한다.**

## 6. 결정이 필요한 것

| | 물음 |
|---|---|
| ① | **ⓐ(가정만) 냐 ⓑ(생성 로직) 냐**(4.3) — 추천은 ⓑ |
| ② | **램프업 수치가 맞나**(4.2) — 18 개월 · 0.85→0.94 · 인증 12 개월. **도메인 검토 대상** |
| ③ | 고객 인증을 데이터로 표현할 것인가 — `QLT-01` 에 인증 단계를 담을지, 프로파일 가정으로 둘지 |
| ④ | 신규 사업을 **분류에서 찾는 경로**를 만들 것인가(3.2) — 투자·증설 공시 기반. 이 검토의 범위 밖이지만 남는 과제다 |

★ ②가 먼저다. 수치가 틀리면 ⓑ로 만든 데이터가 오히려 오해를 준다.
