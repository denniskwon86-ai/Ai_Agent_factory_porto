# AI Factory Studio 제품 및 기능소개서 v2

기존 `docs/product-feature-guide/`를 보존하고, 사용자 검토 의견을 반영해 전면 재구성한 버전입니다.

## 핵심 변경

- 메타 설명 문구와 구현 완성도 평가 페이지 제거
- 현업 직접 생성 → 중앙 데이터 환류 → 기업 경영 온톨로지 → 시뮬레이션 → 회의·결정 → 실행의 제품 서사 강화
- 온톨로지의 역할을 데이터 원천, 영향 경로, 결정론적 계산과 구분해 명시
- 프로젝트 통제실은 승인된 `Transparent Orchestration` UI 기준 화면 사용
- 에이전트 구성 화면과 실행 연결 그래프를 함께 수록
- 경영 시나리오의 실제 수치 비교 결과 수록
- 의사결정 센터의 회의 요청 입력 화면 수록
- 대내외 발간의 실제 보고서 본문 예시 수록
- 전사 브리핑의 실제 우선 조치 내용 수록
- 현재 제품·승인 목표·설계 완료/구현 대기 상태를 문서 안에서 구분
- 실제 화면의 개발 흔적이 제품 운영 데이터로 오해되지 않도록 `검증용 예시 데이터` 표기
- 첫 수직 폐루프를 성과 주장 대신 Shadow Pilot 검증 계약으로 정정
- 90일 파일럿의 측정 KPI·비용 항목·확산/중단 Gate 수록
- ERP·MES·WMS·EPM·BI·Low-code·Data Platform·전문 Twin과의 보완/대체 범위 명시
- 측정되지 않은 ROI·절감액·완성 기능은 주장하지 않는 증거 우선 원칙 적용

## 문서 구성

- 총 26면
- 1~8면: 제품 사상·온톨로지·경영 질문·신뢰 모델·기능 지도
- 9~21면: 제품 기능과 작업 화면
- 22면: 원료 구매→현금·손익 첫 수직 폐루프 검증 계약
- 23면: 90일 파일럿·가치 측정·확산/중단 Gate
- 24면: 기존 시스템 및 대안과의 역할 구분
- 25~26면: 제품 해자와 결론

## 열기

`index.html`을 브라우저로 열거나 정적 서버에서 `/docs/product-feature-guide-v2/`로 접근합니다.

## PDF

문서 우측 상단의 `PDF로 저장`을 사용하거나 Chromium print-to-PDF로 생성합니다. 인쇄 설정은 배경 그래픽 활성화, 여백 없음, 배율 100%를 기준으로 합니다. 공식 배포 PDF는 접근성 태그와 문서 개요를 포함해 별도로 생성·검증합니다.
