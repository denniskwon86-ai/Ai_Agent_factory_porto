## 📊 1. 2026년형 3-Tier 하이브리드 구성 및 단가 (가정)

한 번의 시뮬레이션 프로젝트(1회 완주) 시 **총 36만 토큰(Input 30만 / Output 6만)**이 소모되며, 이 중 역할(Role)에 따라 비용이 다르게 책정됩니다.

### 🧠 A급: 아키텍트/의사결정 노드 (전체 비중 10%)
- **적용 모델**: `GPT-5.6` 또는 `Claude Opus 4.8` (지구상 최고의 추론 모델)
- **단가 (1M 당)**: Input $10.0 / Output $30.0
- **1회 완주 시 비용**: 약 **$0.48** (Input 3만 / Output 6천 토큰)

### 🧑‍🔧 B급: 공학/시뮬레이션 실무 노드 (전체 비중 50%)
- **적용 모델**: `Claude Fable 5` + `LG EXAONE 최신버전` (도메인/수학 특화 가성비)
- **단가 (1M 당)**: Input $2.0 / Output $8.0
- **1회 완주 시 비용**: 약 **$0.54** (Input 15만 / Output 3만 토큰)

### 🤖 C급: 단순 로그/검수 노동 노드 (전체 비중 40%)
- **적용 모델**: 기존에 발급된 **무료(Free Tier) API 키 (Gemini Free 등)**
- **단가**: **$0** (비용 원천 차단)
- **1회 완주 시 비용**: **$0.0** (Input 12만 / Output 2.4만 토큰 소모하나 과금 안 됨)

> **✨ 1회 팩토리 완주 시 총 결제 예상 금액 = $1.02**

- **산출 비용**: 10회 × $1.02
- **🔥 월간 총비용**: **약 $10.2 (한화 약 13,000원)**
- **평가**: GPT-5.6과 EXAONE을 맛보기로 쓰면서도 한 달 요금이 넷플릭스 구독료 수준입니다.

- **🔥 월간 총비용**: **약 $30.6 (한화 약 40,000원)**
