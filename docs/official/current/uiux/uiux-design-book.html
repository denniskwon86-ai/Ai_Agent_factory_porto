01 Principles

제품 경험 원칙

업무에서 시작한다

메뉴나 기술 용어가 아니라 사용자가 해결할 업무, 선택한 회사·조직·기간에서 시작합니다.

한 번 입력한 사실을 다시 쓰지 않는다

원천 시스템 읽기, Source Binding, AFS_NATIVE 입력을 구분하고 이중 입력을 기본적으로 차단합니다.

숫자는 계산하고 AI는 설명한다

온톨로지는 영향 경로, 계산 그래프는 수치, LLM은 요약·질문·설명을 담당합니다.

보이지 않는 것은 존재도 누설하지 않는다

조직·앱·계약 범위 밖 자원은 NOT_FOUND로 접고, 사용자가 고칠 수 있는 자기 문맥 문제만 구체적으로 안내합니다.

상태를 숨기지 않는다

현재 구현, 제한 구현, 목표 UI, 구현 대기, 합성 시연을 명확한 배지로 구분합니다.

보고에서 실행으로 돌아온다

브리핑은 끝이 아니라 회의 요청, 결정, 담당자·기한, 실제 효과 측정으로 연결됩니다.

02 Information Architecture

글로벌 화면 구조

Global Header

제품명, 세션, 도움말, 알림, 실행 상태. 자격증명이나 내부 ID는 노출하지 않습니다.

Company Context Bar

선택 회사·조직·Entity Mode·기간을 표시합니다. 문맥이 없으면 실행보다 선택 안내가 우선합니다.

Workspace + Evidence

중앙 작업영역과 오른쪽 근거·결정 Drawer를 분리해 현재 업무와 추적 정보를 함께 봅니다.

1차 영역사용자 질문대표 화면
업무·데이터 설계 상담무엇을 만들고 어떤 데이터를 준비해야 하는가?Advisor, Software Factory, Build/Preview
협업·의사결정·발간누가 무엇을 검토·결정·발간해야 하는가?Decision Center, Collaboration, Publication
전사 브리핑지금 경영자가 봐야 할 변화와 조치는 무엇인가?Management Home, Briefing, Decision Canvas
데이터 기반숫자의 원천·계약·품질·계보는 무엇인가?Knowledge Hub, MDM, Data Prep, Governance
업무 표준·조직누가 어떤 기준과 권한으로 일하는가?Work Standard, Org & Permissions, Agent Control
운영·검증계획·시나리오·텔레메트리·Shadow 결과는 어떤가?Planning, Scenario, Shadow Mode, Telemetry

Typography

Pretendard → Noto Sans KR → Segoe UI. 본문 14–16px, 표 12–14px, H1은 유동형 크기를 사용합니다.

Spacing

4px 기본 단위. 컨트롤 8/12px, 카드 20–24px, 섹션 40–72px. 밀도는 정보량에 따라 조정합니다.

Elevation

기본 면은 border, 선택·Modal만 shadow. 그림자로 계층을 남발하지 않습니다.

05 Product Status Language

구현·증거 상태 표기

CURRENT VERIFIED

현재 제품에 배선돼 있고 회귀 또는 종단 검증이 있습니다.

CURRENT LIMITED

일부 사용자·범위·데이터만 지원하거나 종단 근거가 부족합니다.

APPROVED TARGET

승인된 제품 방향이나 UI이지만 현재 화면과 같다고 주장하지 않습니다.

DESIGNED / PENDING

설계는 있으나 제품 런타임 또는 UI 배선이 완료되지 않았습니다.

DEMO PROVEN

합성·검증용 데이터로 재현했습니다. 실제 고객 실적이 아닙니다.

NOT SUPPORTED

우회나 묵시적 폴백 없이 명시적으로 막고 다음 조치를 안내합니다.

06 Accessibility & Content

접근성·문장 원칙

접근성

  • 본문 대비 4.5:1 이상
  • 키보드 포커스와 논리적 Tab 순서
  • 최소 터치 목표 44px
  • 아이콘 단독 행동에 접근 가능한 이름
  • 표는 헤더·단위·빈 상태를 명시

제품 문장

  • 기술 사유보다 사용자가 할 다음 행동을 먼저
  • 실적·공식·인증 용어는 근거가 있을 때만
  • 측정 전 효과는 목표 또는 가설로 표기
  • 내부 ID·해시·tenant_default는 외부 화면에서 숨김
  • Jarvis는 개발 가칭이며 공식 문서에는 AI 경영비서 또는 실제 기능명을 사용
