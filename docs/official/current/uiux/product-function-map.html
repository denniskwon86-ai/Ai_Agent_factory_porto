04 Persona Map

사용자별 대표 여정

현업 담당자

키트를 선택하고 앱을 만들며, 기존 시스템에 없는 보충 사실을 한 번만 기록합니다.

Data Owner

원천·계약·품질·Snapshot을 검토하고 공식성과 합성 데이터를 구분합니다.

기획·재무

기준선과 시나리오를 비교하고 계산 근거와 손익·현금 영향을 검증합니다.

경영자

우선 질문, 영향 경로, 숫자, 대안, 책임자·기한을 보고 결정을 내립니다.

AX/Product Lead

업무키트·제품 로드맵·승격·재사용과 기능 품질을 관리합니다.

관리자·CIO

조직·권한·테넌트·Agent·정책·감사·비용·장애를 통제합니다.

협업 참여자

회의 요청·검토·결정·발간 승인과 후속 조치를 수행합니다.

외부 이해관계자

승인된 보고서와 제한된 입력 표면만 사용하며 내부 시스템 권한은 받지 않습니다.
