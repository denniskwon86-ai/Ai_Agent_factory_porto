Decisions

ID결정근거효력
D-01Markdown 설계·인계 문서는 이동하지 않는다.개발 정본과 사람용 배포 문서의 목적이 다름즉시
D-02공식 문서 센터는 HTML·PDF·DOCX와 시각 자산만 관리한다.읽기·배포·히스토리 경계를 단순화즉시
D-03공식 기능명은 AI 경영비서로 쓰고, 사용자 화면의 비서 호칭은 자비스로 표시한다.기능의 역할과 대화형 정체성을 구분해 문서와 화면을 일치현행 UI 기준
D-04온톨로지는 경로를 찾고 G4가 수치를 계산하며 LLM은 설명한다.환각·책임·재현성 경계제품 원칙
