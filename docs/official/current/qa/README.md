# 기능 점검표

**[functional-checklist.html](functional-checklist.html)** — 브라우저로 열어서 씁니다.

화면에서 직접 눌러 확인하고, 항목마다 **정상 / 문제 / 일부 / 해당없음** 을 고르고
**특이사항**을 적습니다. 입력은 브라우저에 자동 저장되고, **CSV 로 내보내면 엑셀에서
그대로** 열립니다(BOM 을 붙여 한글이 깨지지 않습니다).

## 왜 MD 가 아닌가

점검은 **적으면서** 하는 일이다. MD 문서는 읽기만 되고, 결과를 남기려면 사본을 만들어
손으로 표를 채워야 한다 — 그러면 항목이 조금씩 달라진 사본이 여러 개 생긴다.
정본은 항목 목록 하나(`_checklist_items.py`)이고, 화면은 거기서 생성한다.

## 고칠 때

항목을 더하거나 고치려면 **`_checklist_items.py` 만** 고치고 다시 생성한다:

```
cd docs/official/current/qa
../../../../venv/Scripts/python.exe _build_checklist.py
```

⚠️ `functional-checklist.html` 을 직접 고치지 않는다 — 다음 생성 때 사라진다.

## 판정을 적는 규칙

- **문제 / 일부** 는 특이사항이 **필수**다. 「안 된다」만으로는 고칠 수 없다 —
  무엇을 눌렀고, 무엇이 보였고, 무엇을 기대했는지 적는다.
- **해당없음** 은 「이 설치본에 그 기능이 없다」이지 「확인 안 했다」가 아니다.
  확인하지 않은 것은 **비워 둔다** — 미확인과 정상을 같은 칸에 넣지 않는다.
