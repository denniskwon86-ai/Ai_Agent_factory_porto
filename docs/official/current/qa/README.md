## 핵심 실행 순서

조직 문맥을 고른 뒤 아래 다섯 메뉴를 순서대로 확인합니다.

1. 업무 데이터 준비
2. 계산 실행 승인
3. 경로 계산
4. 의사결정 안건
5. 경영 브리핑

`frontend/src/App.tsx`의 현재 메뉴 기준은 기본 진입 2개와 전체 메뉴 24개, 합계
26개입니다. 화면 지도는 이 26개 메뉴뿐 아니라 홈·상단 바·업무키트 상세·Software
Factory 상세처럼 사용자가 실제로 거치는 화면도 별도 확인 지점으로 다룹니다.

## 판정을 적는 규칙

- **문제 / 일부**는 특이사항이 필수입니다. 무엇을 눌렀고, 무엇이 보였고, 무엇을
  기대했는지 적습니다.
- **해당없음**은 이 설치본에 그 기능이 없다는 뜻입니다. 확인하지 않은 항목은 비워
  둡니다. 미확인과 정상을 같은 칸에 넣지 않습니다.
- 코드에 구현돼 있다는 사실만으로 정상 판정하지 않습니다. `127.0.0.1:5173`에서
  실제 사용자 경로를 눌러 확인합니다.
- 내부 ID·코드를 사용자가 직접 입력해야 정상 동작한다면 **문제**입니다.

## 정본과 생성

점검은 읽는 문서가 아니라 결과를 남기는 도구입니다. 항목 정본은 파이썬 파일 하나씩만
유지하고 HTML은 생성합니다.

```text
cd docs/official/current/qa
../../../../venv/Scripts/python.exe _build_checklist.py
../../../../venv/Scripts/python.exe _build_screenmap.py
```

- 화면 지도 정본: `_screenmap_items.py`
- 기능 점검 정본: `_checklist_items.py`
- 생성 결과: `screen-map.html`, `functional-checklist.html`

생성된 HTML을 직접 고치지 않습니다. 다음 생성에서 사라집니다. 메뉴가 바뀌면
`App.tsx`와 `_screenmap_items.py`를 함께 고치고, 두 생성기를 다시 실행합니다.
