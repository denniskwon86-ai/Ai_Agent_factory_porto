AI Factory Studio — 화면 지도

어떤 화면이 있고 · 어디를 눌러 열고 · 무엇을 하는 곳인지. 열어 보고 판정과 특이사항을 적습니다.
이 시스템의 핵심은 ①번 다섯 단계입니다 — 조직 고르기 → 업무 데이터 준비 → 계산 실행 승인 → 경로 계산 → 의사결정 안건. 나머지 화면은 그 다섯을 받쳐 주거나 결과를 확인하는 곳입니다.
판정 — 열림 눌러서 열리고 내용이 있다 · 안 열림 눌러도 아무 일이 없거나 오류 · 열리나 빔 열리지만 비어 있거나 무엇을 해야 할지 모르겠다 · 권한 없음 이 계정 권한으로는 못 본다(그렇게 안내하면 정상). 「안 열림」과 「열리나 빔」은 특이사항 필수입니다.

#화면여는 길무엇을 하는 곳 주요 행동선행 조건판정특이사항
① 처음 여는 사람이 밟는 길 — 이 다섯이 핵심 여정이다
1 1단계 · 조직 고르기 좌상단 «조직 전환 ▾» → 부서 선택 지금 어느 조직의 자료를 보는지 정한다. **여기서 고르지 않으면 뒤의 화면 대부분이 비거나 막힌다.** 부서 선택 없음 — 로그인 직후 첫 행동이다
2 2단계 · 업무 데이터 준비 «전체 메뉴» → 📥 업무 데이터 준비 → 인스턴스 «열기» 업무 키트를 조직에 적용하고, 원천을 연결하고, 파일 판을 인증한다. 여기서 «준비됨»이 되어야 계산이 돈다. 원천 결속 · 파일 올리기 · 판 인증 1단계
3 3단계 · 계산 실행 승인 «전체 메뉴» → 🔐 계산 실행 승인 · 시연 초기화 산식을 실제로 돌려도 되는지 사람이 승인한다. **누르기 전까지 계산은 «막힘»으로 답한다.** 정의·단위·부호 확인 후 승인 2단계 · 시스템 관리자 권한
4 4단계 · 경로 계산 «전체 메뉴» → 🧮 경로 계산 승인된 관계를 따라가 부족량·생산가능량·매출 이연을 계산한다. **이 시스템의 핵심 산출물이다.** 시작점 선택 → 경로 조회 → 계산 3단계
5 5단계 · 의사결정 안건 «전체 메뉴» → 🧭 의사결정 안건 계산 결과를 3관점 검토서와 책임자·기한이 붙은 안건으로 만든다. 안건 생성 · 검토 · 발간 4단계 (BLOCKED 로는 안 만들어진다)
② 상단 바 — 항상 보이는 것
6 조직 전환 좌상단 «조직 전환 ▾» 보는 조직 범위를 바꾼다. 바꾸면 화면이 새로 뜬다(이전 자료가 남지 않는다). 부서 선택 없음
7 회사·범위 표시 상단 바 왼쪽 텍스트 지금 소속 회사와 보는 범위를 적는다. 안 골랐으면 「권한 범위 전체」다. 표시 전용 없음
8 환경설정 · 관리자 우상단 «환경설정 · 관리자» 내 정보(표시 이름)·시스템 설정·관리자 기능 입구. 이름 변경 · 설정 없음
9 전사 브리핑 우상단 «전사 브리핑» 권한 범위 안의 전사 상태 — 내가 결정할 것·막힌 것·데이터 결손·비용. LLM 0콜. 상세 열기 없음
10 전체 메뉴 우상단 «전체 메뉴» 20개 화면 전체 목록. 핵심 여정이 맨 위이고 6묶음으로 나뉜다. 화면 선택 없음
11 로그아웃 우상단 «로그아웃» 세션을 끝낸다. 로그아웃 없음
③ 경영 홈 본문 — 로그인하면 처음 보이는 화면
12 문맥 줄 본문 맨 위 기준시각 · 실행 문맥(REAL/VIRTUAL) · 조직 이름. **지금 무엇을 보고 있는가**에 답한다. 표시 전용 없음
13 업무 SW 만들기 본문 맨 위 «🏭 업무 SW 만들기 — Software Factory» 요구사항에서 업무 소프트웨어를 생성하는 공장 입구. 프로젝트 생성 없음
14 무엇을 만들지 상담 본문 맨 위 «🧭 무엇을 만들지 상담» 무엇을 만들지 모를 때 — 선택형 대화로 필요한 데이터와 추진 순서를 정한다. 승인하면 프로젝트가 된다. 상담 진행 · 승인 없음
15 협업·의사결정·발간 본문 맨 위 «🤝 협업·의사결정·발간» 앱 전달·수락, 의사결정 패키지, 대내외 발간. 수락해도 데이터 권한은 넓어지지 않는다. 전달 · 수락 · 발간 없음
16 KPI 4칸 문맥 줄 아래 내가 결정할 것 · 막혀 있는 것 · 업무 도메인 · LLM 비용. 표시 전용 없음
17 업무 흐름 (DATA/SW/TWIN) KPI 아래 탭 조직 트리를 업무 축으로 본다. 공정 프로필이 없으면 그렇게 적는다. 탭 전환 · 노드 선택 없음
18 DECISION FOCUS 본문 가운데 지금 답해야 할 것 하나와 다음 행동. 상세 열기 없음

20 Jarvis 패널 화면 오른쪽 지금 보는 문맥에 대한 답변·근거·기준시각. 질문 · 근거 열기 없음
④ 전체 메뉴 › 핵심 여정 — 이 넷을 순서대로
21 1️⃣ 업무 데이터 준비 전체 메뉴 → 1️⃣ 업무 데이터 준비 업무키트를 조직에 적용하고 · 원천을 연결하고 · 파일 판을 인증합니다 — 여기가 «준비됨»이어야 뒤가 돕니다. 인스턴스 열기 · 결속 · 인증 · 앱 만들기 조직 범위 선택
