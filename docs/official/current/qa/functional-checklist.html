#점검 항목어떻게 확인하나기대 결과 판정특이사항
A. 접속·인증·문맥
1 로그인 로그아웃 상태에서 화면을 열고 아이디·비밀번호로 로그인한다. 로그인되고 좌상단에 내 이름과 소속 회사가 보인다. 초기 비밀번호면 변경 안내가 뜬다.
2 내 이름 바꾸기 환경설정 · 관리자 → 내 정보에서 표시 이름을 바꾼다. 저장되고 상단에 바뀐 이름이 보인다. 관리자 권한은 그대로 유지된다.
3 조직 범위 전환 좌상단 «조직 전환» 에서 하위 부서를 고른다. 본문 맨 위 문맥 줄이 그 부서 이름으로 바뀐다(원시 id 가 아니다).
4 범위 미선택 상태 «조직 전환» 에서 아무것도 고르지 않은 상태로 둔다. 「권한 범위 전체」 또는 「내 소속 전체」로 표시된다. 없는 부서를 지어내지 않는다.
5 로그아웃 로그아웃을 누른 뒤 뒤로 가기를 눌러 본다. 다시 로그인 화면이다. 이전 화면의 자료가 남지 않는다.
6 전체 메뉴 26개 전체 메뉴를 열고 그룹별 항목을 센다. 기본 진입 2개와 전체 메뉴 24개가 현재 화면 순서대로 보이며, 누르면 각각의 화면이 열린다.
B. 조직·권한
7 사용자 목록 환경설정 · 관리자 → 조직·권한 에서 사용자 목록을 연다. 사용자가 목록으로 보이고 부서·권한 표식이 함께 뜬다.
8 사용자 추가 새 사용자를 하나 만든다(예: 테스트 계정). 200 으로 저장되고 목록에 즉시 나타난다. 500 이 나면 안 된다.
9 권한 칸 만든 사용자에게 데이터 관리자 권한을 켠다. 켜지고 다시 열어도 유지된다. 행위자 값이 권한 칸으로 새지 않는다.
10 부서 계층 부서 트리를 펼쳐 상·하위 관계를 본다. 상위를 고르면 하위 자료까지 보이고, 하위를 고르면 그 범위만 보인다.
11 회사별 업무 구성 전체 메뉴 → 회사 구성에서 현재 회사를 선택한다. 실제 회사명과 연결된 업무 흐름·보조정보 구성이 보이고, 권한 있는 사용자는 개정할 수 있다.
12 권한 없는 접근 일반 사용자로 로그인해 관리자 화면을 연다. 403 으로 막히고 왜 막혔는지 문장으로 말한다.
C. 업무 데이터 준비 (업무 키트)
13 키트 목록 전체 메뉴 → 업무 데이터 준비. 등록된 업무 데이터 키트가 이름·판본·자료 성격과 함께 보인다.
14 인스턴스 열기 키트 인스턴스를 연다. 필요 데이터셋 목록과 각각의 준비 상태가 보인다.
15 준비도 표시 데이터셋별 상태를 확인한다. 「준비됨 / 오래됨 / 막힘」이 구분되고, 막힌 것은 다음 할 일을 말한다.
16 원천 결속 데이터셋 하나에 원천을 연결한다. 연결·검증·승인·활성 단계가 순서대로 진행된다.
17 파일 판 인증 파일을 올려 판을 인증한다. 행 수·품질 검사 결과가 보이고 인증된 판에 지문이 붙는다.
18 소유권 결속 데이터셋 소유 부서가 지정돼 있는지 본다. 소유 부서가 있고, 인증보다 먼저 결속돼 색인에 소유자가 채워져 있다.
D. 계산 실행 승인
19 제안서 화면 전체 메뉴 → 계산 실행 승인 · 시연 초기화. 산식별 정의·단위·부호·범위·유효기간이 보인다. 누르기 전에는 아무것도 승인되지 않는다.
20 승인 범위 제안서의 «실행 모드» 를 확인한다. 인스턴스와 같은 값이다(고를 수 없다). 다르면 그 승인은 계산에 붙지 않는다.
21 승인 누르기 근거를 적고 승인한다. 능력마다 별도 원장 사건이 남는다. 준비도 관문이 READY 로 바뀐다.
22 권한 분리 일반 사용자·데이터 관리자로 같은 버튼을 눌러 본다. 시스템 관리자만 누를 수 있다. 나머지는 403 이고 사건이 남지 않는다.
23 승인 철회 승인 하나를 철회한다. 철회되고 계산이 다시 BLOCKED 로 답한다.
E. 경로 탐색·계산 (핵심 수직)
24 시작점 목록 전체 메뉴 → 경로 계산 에서 시작점을 고른다. 고를 수 있는 객체가 목록으로 뜬다(손으로 id 를 치지 않는다).
25 영향 경로 출하 → 판매행 경로를 조회한다. COMPLETE 로 경로가 나오고 마디가 순서대로 보인다. 503 이면 안 된다.
26 경로 계산 그 경로로 계산을 실행한다. 부족량·생산가능량·매출이연 일수가 숫자로 나온다.
27 막힘 사유 승인이 없거나 자료가 부족한 상태로 계산해 본다. 200 + BLOCKED 이고 무엇이 없어서 막혔는지 사람 말로 말한다.
28 가정 표시 계산에 쓴 가정을 확인한다. 쓴 가정이 결과와 함께 보인다(예약수량 0 가정 등). 지문에 포함된다.
29 쓴 판 표시 계산이 어느 인증판을 읽었는지 본다. 계약별 인증판 이름·기준시각·지문이 함께 나온다. 내부 판 ID를 사용자가 입력하지 않는다.
F. 산출물 앱
30 앱 목록 인스턴스 화면 아래 «키트로 앱 만들기». 앱이 이름과 함께 보인다. 내부 코드만 단독으로 노출되면 안 된다.
31 계약 초안 앱 분류를 고르고 계약 초안을 만든다. 초안이 생기고 「승인 대기」로 바뀐다.
32 직무 분리 초안을 만든 사람이 직접 승인해 본다. 422 로 막히고 왜 막혔는지 말한다.
33 다른 사람 승인 다른 관리자로 로그인해 승인한다. 승인되고 원장 사건이 남는다.
34 앱 만들기 «앱 만들기» 를 누른다. 데이터셋이 만들어지고 목록에 개수가 표시된다.
35 두 번 누르기 «다시 만들기» 를 한 번 더 누른다. 200 이고 데이터셋이 늘어나지 않는다(같은 자리를 이어받는다).
36 운영 전환 근거를 적고 «운영으로 올리기» 를 누른다. 다섯 관문이 전부 통과하고 「운영 중」으로 바뀐다.
37 앱 열어 보기 «앱 열어 보기» 를 누른다. 인증된 업무 데이터가 표로 보인다(자재·수량·날짜 등 업무 칸 포함).
38 범위 미선택 시 조직 범위를 안 고른 채 앱을 열어 본다. 「조직 범위를 선택해야 앱이 데이터에 연결됩니다」로 안내한다.
G. 의사결정·협업
39 의사결정 안건 전체 메뉴 → 의사결정 안건. 영향 경로·3관점 검토서·책임자·기한이 보인다.
40 안건 생성 계산 결과로 안건을 만든다. 계산 결속과 봉인 판이 근거로 함께 저장된다. BLOCKED 로는 만들어지지 않는다.
41 협업·발간 전체 메뉴 → 협업·의사결정·발간. 앱 전달·수신함·발간 목록이 보인다.
42 전사 브리핑 상단 «전사 브리핑». 지금 결정할 것·막힌 것이 근거와 함께 보인다.
43 경영 브리핑 전체 메뉴 → 경영 브리핑. 확정 안건·실행 상태·기준시각·근거가 함께 보이며, 확인하지 못한 값을 정상 또는 0으로 표시하지 않는다.
H. 시뮬레이션·경영계획
44 시나리오 전체 메뉴 → 시나리오 시뮬레이션. 환율·지연·전력단가를 바꾸면 생산량·재고·현금이 바뀐다.
45 기준선 비교 기준과 시나리오를 비교한다. 두 값이 나란히 보이고 차이가 계산된다. 과거 실적을 시뮬레이션 결과로 보여주지 않는다.
46 경영계획 전체 메뉴 → 경영계획. 계획·실적·시나리오가 같은 기준선에서 비교된다.
I. SW 생성 (Software Factory)
47 상담 «무엇을 만들지 상담». 요구를 묻고 답에 따라 다음 질문이 달라진다.
48 프로젝트 생성 «업무 SW 만들기» 에서 프로젝트를 만든다. 워크플로우가 시작되고 단계별 진행이 보인다.
49 산출물·릴리스 생성된 산출물과 릴리스를 확인한다. 코드·문서가 남고 릴리스가 후보 판으로 게시된다.
50 운영 승격 전체 메뉴 → 운영 승격. 계약·물질화·정적검사·승인·데이터 준비도를 다시 보고 하나라도 어긋나면 막는다.
J. 기준정보·지식·외부지표
51 기준정보 마스터 전체 메뉴 → 기준정보 마스터. 자재·공정·설비·KPI 골든 레코드가 보이고 확정 조회가 된다.
52 용어집 전체 메뉴 → 기술·제품 용어집. 현재 용어·권장 용어·표준명이 함께 보인다. 화면이 느려지지 않는다.
53 지식 허브 전체 메뉴 → 지식 허브. 문서를 올리면 청크·검토 대기가 표시되고 승인 후에 쓰인다.
54 업무 온톨로지 전체 메뉴 → 업무 온톨로지에서 객체 하나를 선택한다. 관계 그래프가 보이고 선택한 관계의 방향·유효시점·승인 상태·근거를 상세에서 확인할 수 있다.
55 외부지표 TRUST FOUNDATION → 외부지표. 지표별 vintage·지연이 표시된다. 확인 못 한 것을 「정상」으로 세지 않는다.
56 외부 수집 봇 전체 메뉴 → 대외 인텔리전스에서 회사·사업 기준 수집을 실행한다. 수집 후보와 출처·수집시각이 먼저 보이고, 사람이 승인한 항목만 확정 지표와 기초 데이터로 승격된다.
57 연계/크로스워크 전체 메뉴 → 연계/크로스워크. 외부 시스템 키·필드가 기준정보에 매핑된다.
K. 거버넌스·감사
58 데이터 거버넌스 전체 메뉴 → 데이터 거버넌스. 조직 범위 노출·중복 기준정보·카탈로그 결손이 건수로 보인다.
59 결정 원장 승인·거부 기록을 조회한다. 행위자·시각·사유·대상이 남는다. 수정·삭제가 되지 않는다.
60 업무표준 전체 메뉴 → 업무표준. 에이전트가 무엇을 어떤 기준으로 평가하는지 보인다.
61 에이전트 통제소 전체 메뉴 → 에이전트 통제소. 역할·스킬·모델·순서·HOTL 지점이 보이고 바꿀 수 있다.
62 에이전트 추천·생성 에이전트 통제소에서 필요한 업무를 자연어로 입력한다. 역할과 스킬을 추천하고 검토 후 생성한다. 사용자가 에이전트 ID나 코드를 직접 입력하지 않는다.
63 워크플로우 템플릿 에이전트 화면의 첫 메뉴에서 워크플로우 템플릿을 고른다. 선택한 템플릿의 에이전트 세트와 실행 순서가 화면과 실행 흐름에 동일하게 반영된다.
64 AI 스킬 진화 전체 메뉴 → AI 스킬 진화. 제안을 승인/반려할 수 있고 반려한 것은 반영되지 않는다.
65 LLM 텔레메트리 전체 메뉴 → LLM 텔레메트리. 실제 사용 모델·폴백·소요시간이 보인다. 고른 모델과 다르면 드러난다.
L. 경계·안전 (반드시 확인)
66 테넌트 경계 다른 회사 자료의 id 를 직접 넣어 조회해 본다. 404 로 은폐한다. 403 이면 그 자료의 존재가 새어 나간다.
67 조직 경계 내 범위 밖 부서의 자료를 조회해 본다. 보이지 않는다. 「없음」과 「못 봄」이 같은 답이다.
68 미지정 자료 범위가 지정되지 않은 자료를 조회해 본다. 비노출이다 — 「전사 공용」으로 열리면 안 된다.
69 빈 값 처리 자료가 없는 화면을 연다. 「0 건」과 「확인하지 못함」이 구분돼 보인다.
70 동시 편집 두 창에서 같은 것을 고친다. 나중 저장이 앞의 것을 조용히 덮지 않는다.
71 실행 문맥 표시 REAL / VIRTUAL / DEMO 자료를 각각 연다. 화면이 어떤 자료인지 항상 적는다. 시연 자료가 실적으로 보이지 않는다.
72 시스템 식별자 등록·생성 화면에서 새 회사·사용자·에이전트·프로젝트·안건을 만든다. 사용자는 이름과 업무 정보만 입력한다. ID·코드는 채번 규칙에 따라 시스템이 생성하며 입력칸에 노출되지 않는다.
M. 화면 품질
73 가독성 각 화면의 글자·테두리 대비를 본다. 흰 바탕에 흰 계열 글자·테두리가 없다. 12px 미만 업무 텍스트가 없다.
74 반투명 팝업 팝업·대화상자를 연다. 뒤 내용이 비쳐 보이지 않는다.
75 자비스 영역 창 너비를 줄였다 늘린다. 오른쪽 AI 경영비서(자비스) 패널이 깨져 아래로 붙지 않고, 질문 입력과 답변이 겹치지 않는다.
76 공통 화면 골격 앱 제작·앱 운영·시뮬레이션·결정 보고·지식·에이전트 화면을 차례로 연다. 좌측 메뉴·중앙 업무·우측 AI 경영비서의 배치와 상단 메뉴의 높이·색·글꼴이 같은 규칙을 따른다.
77 못 누르는 버튼 비활성 버튼에 마우스를 올린다. 왜 못 누르는지 말한다.
78 첫 화면 머리 경영 홈을 연다. 기준시각·실행 문맥·조직과 주요 행동 버튼이 본문 맨 위에 있다.
