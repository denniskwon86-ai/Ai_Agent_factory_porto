## 4. 나레이션

### 4.1 어투·끊김 개선

| 문제 | 조치 |
|---|---|
| 슬라이드마다 검정 페이드 + 1.6초 침묵 → 뚝 끊김 | **크로스페이드**(0.6초)로 연결, 앞 여유 0.5초·뒤 여유 0.7초로 축소 |
| 문장 사이 호흡이 TTS 임의 | **문장 단위로 생성**해 앞뒤 무음을 잘라내고 문장 사이 호흡을 **0.35초로 일정하게** 삽입 |
| 단문 나열의 딱딱한 어투 | "그래서", "하지만", "그 아래에는" 같은 연결어, "~에 그대로 두고 … 봉인합니다" 식의 이어지는 문장으로 재작성 |
| 속도 | +8% → **+6%** |

### 4.2 음성 — Microsoft Edge Neural (`edge-tts`), `ko-KR-SunHiNeural`

- ⚠️ 온라인 방식 — 대본이 Microsoft 음성 서비스로 전송된다. 대외 배포 문서 수준의 문장만 쓴다.
- 대안 음성 `InJoonNeural`·`HyunsuMultilingualNeural`(남성). 비교 샘플은 `output/video/compare/`에 만들었다(git 제외).

### 4.3 영문 읽기 규칙 (자동 치환, `scripts/video/make_tts.py`)

| 규칙 | 예 |
|---|---|
| 영문 약어는 글자마다 독립 음절 | AX → 에이엑스 · ERP → 이알피 · MES → 엠이에스 · LPL → 엘피엘 · AI → 에이아이 |
| 문서가 발음을 정의한 고유명 | LAXS → **랙스**, LAXS-M → 랙스 엠 |
| 회사명 | LS MnM → 엘에스 엠엔엠 · LS → 엘에스 |
| 조사가 붙어도 치환 | `AX를` → 에이엑스를, `LPL과` → 엘피엘과 (16장 41문장 미치환 0건 검증) |

표시용 대본(자막)에는 원문 `AX`·`ERP`가 그대로 보인다.

### 4.4 원칙

1. 슬라이드 텍스트를 읊지 않고 "왜 중요한가"를 말한다. 경영 보고 문체, 과장 없음.
2. 수치는 문서에 있는 것만. 시뮬레이션 화면은 **합성 데모 데이터 예시**임을 음성으로 말한다.
3. "AI가 숫자를 지어내지 않습니다", "ERP·MES·LPL을 교체하지 않습니다" — 문서의 비협상 문장은 그대로 쓴다.

## 6. BGM

- 라이선스 문제가 없도록 **로컬에서 합성한 앰비언트 패드**(`scripts/video/make_bgm.py`, numpy): Cmaj7→Am7→Fmaj7→Gadd9 8초 순환, 사인파 패드 + 옥타브 위 벨 톤, 느린 호흡.
- 나레이션 대비 약 −13dB로 깔고, 나레이션 구간에서는 **사이드체인 덕킹**(비율 6:1)으로 자동 감쇠. 영상 총 길이에 맞춰 합성하므로 끝 4초 페이드아웃이 정확히 마지막에 걸린다.
- 상용·CC 음원으로 바꾸려면 `--bgm <파일>`로 교체만 하면 된다(크레딧 표기 의무는 음원 라이선스에 따름).
