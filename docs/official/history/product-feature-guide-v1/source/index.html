Product definition

자동화 도구가 아니라 제조 경영 시스템입니다

AI Factory Studio는 모든 업무를 대체하는 단일 시스템이 아니라, 기존 ERP·MES·LPL·파일·외부 데이터와 공존하며 경영 판단에 필요한 의미와 실행 수단을 연결합니다.

03

Seven product capabilities

일곱 기능이 하나의 경영 운영체계를 만듭니다

개별 기능의 나열이 아니라, 현업 문제를 데이터·SW·시뮬레이션·의사결정으로 이어주는 결합 구조가 제품의 핵심입니다.

1

현업 데이터 연결

마스터·문서·업무 시스템·파일을 등록하고 연결합니다.

2

통합 지식 자산

용어·동의어·연관성·출처를 관리하고 검색·재가공합니다.

3

경영 시뮬레이션

업무 모듈과 전사 관점에서 조건 변화의 영향을 계산합니다.

4

에이전트 워크플로우

역할·스킬·모델·사용자 검토 지점을 조합합니다.

5

문맥형 AI 보좌

선택한 회사·조직·객체·업무 상태를 기준으로 질문에 답하고 다음 행동을 안내합니다.

6

조직별 생성·공유

회사·사업부·공장·부서 권한에 따라 앱·데이터·시뮬레이터를 만들고 공유합니다.

7

전사 통합 경영

부서별 기능을 연결해 경영 실적과 미래 시나리오를 전사 관점으로 집계합니다.

궁극적 질문

“환율·전기료·고용·원료가격이 바뀌면 올해 하반기, 내년, 후년의 매출·손익·현금흐름은 어떻게 달라지는가?”

04

Closed loop

데이터를 보고서로 끝내지 않고 실행과 학습으로 되돌립니다

의사결정에 사용한 근거와 계산을 고정하고, 실행 결과를 다시 측정해 다음 계획과 지식에 반영하는 폐루프가 제품의 장기 해자입니다.

① 연결ERP·MES·파일·외부지표
② 의미화MDM·용어·계보·온톨로지
③ 생성업무 SW·보고서·시뮬레이터
④ 계산시나리오·민감도·백테스트
⑤ 검토근거·리스크·영향부서
⑥ 결정승인·조건부 승인·반려
⑦ 실행담당·기한·업무 시스템 반영
⑧ 환류효과 측정·지식·스킬 개선

결정론적 숫자

LLM이 숫자를 창작하지 않습니다. 승인된 입력·수식·버전으로 계산하고 입력 차이는 비교 불가로 판정합니다.

근거가 고정된 결정

결정 요청 후 근거가 바뀌면 조용히 덮지 않고 재검토 상태로 전환합니다.

측정 가능한 효과

결정 전후의 목표·실적·오차·비용·사용자 수정량을 남겨 다음 실행의 품질을 높입니다.

핵심 원칙

LLM은 해석·설명·문서화에 사용하고, 경영 수치·권한·승인·배포는 결정론적 엔진과 서버 정책이 통제합니다.

회사 구조와 권한을 가장 먼저 설정합니다

Fail-closed

조직 범위나 바인딩을 해석하지 못하면 전사 공용으로 보지 않고 노출을 차단합니다.

Existing Systems Coexist

외부 참여자 입력은 기존 파트너 시스템에서 받고 검증된 계약을 통해 연결합니다. 경영 시스템을 외부에 개방하지 않습니다.

D

Evidence & Version

출처·버전·유효기간·승인·조직 범위·근거 경로를 보존해 숫자와 판단을 재현합니다.

경영 홈

지금 결정해야 할 것과 데이터 신뢰 상태를 첫 화면에서 확인합니다.

주요 사용자경영진 · 조직 책임자 · PMO

화면 목적

여러 모듈을 순회하기 전에 의사결정 대기·차단·업무 도메인·비용·신뢰 기반을 한곳에서 파악합니다.

핵심 기능

  • 내 결정과 차단 상태 요약
  • DATA·SW·TWIN 업무 흐름
  • MDM·지식·외부지표 신뢰 상태
  • 주요 업무로 바로 이동

출력

현재 경영 초점, 다음 행동, 데이터 준비도, LLM 비용과 호출량.

통제

회사·조직 문맥과 사용자 권한에 따라 카드·수치·결정 목록을 제한합니다.

업무 흐름조직 문맥 선택→결정·차단 확인→근거·신뢰 확인→전문 기능 진입
09
F-02

업무·데이터 설계 상담

무엇을 만들지 모르는 사용자에게 필요한 데이터와 실행 청사진을 먼저 제안합니다.

주요 사용자현업 담당자 · 혁신조직 · 데이터 오너

화면 목적

사용자가 긴 요구서를 쓰기 전에 선택형 상담으로 목표·범위·데이터 준비 수준을 구체화합니다.

핵심 기능

  • 업무 주제 선택
  • 추천안 중심 선택형 질문
  • 필요 데이터셋 자동 제안
  • 워크플로우·산출물 청사진

출력

요구사항 초안, 데이터 요구 목록, 부족 데이터와 대체 경로, 추천 생성 템플릿.

통제

확정되지 않은 가정은 가정으로 표시하고, 사용자가 승인한 내용만 생성 단계로 넘깁니다.

업무 흐름업무 목표 입력→선택형 상담→데이터 준비 확인→청사진 승인

F-03

Software Factory

업무 SW 프로젝트를 만들고, 프로젝트·Mega·릴리스·보관함을 관리합니다.

주요 사용자업무 기획자 · Citizen Developer · PM

화면 목적

현업 앱·보고서·시뮬레이터 생성 작업을 시작하고 전체 생성 자산의 상태를 관리합니다.

핵심 기능

  • 독립·Mega 프로젝트
  • 릴리스와 결과물 보관
  • 회사·조직·템플릿 선택
  • 실제·가상·시험 문맥 분리

출력

프로젝트 메타정보, 적용 템플릿, 초기 요구사항, 생성 작업 ID.

통제

시험 산출물은 실제 경영 집계에서 제외하고, 신규 자산은 명시적 조직 범위를 요구합니다.

업무 흐름유형 선택→조직·템플릿 지정→요구 입력→통제실 생성
11
F-04

프로젝트 통제실

요구확인부터 릴리스까지 전체 단계를 숨기지 않고 사용자 검토와 함께 진행합니다.

주요 사용자프로젝트 오너 · 검토자 · 운영 책임자

화면 목적

에이전트 작업이 암묵지가 되지 않도록 단계·WBS·실시간 기록·사용자 결정·산출물을 동시에 보여줍니다.

핵심 기능

  • 전체 워크플로우 스트립
  • WBS 진행·현재 작업
  • 사용자 검토 요청
  • 코드·문서·미리보기
  • 문맥형 AI 보좌

출력

RFP·기획·UI·아키텍처·WBS·기술설계·코드·검수·매뉴얼.

통제

사용자 검토 지점, 재작업 한도, 빌드·회귀·QA 게이트, 격리된 미리보기.

업무 흐름질문·요구정의→설계·WBS→구현·검증→릴리스·전달
12
F-05

지식 허브

승인된 문서와 근거를 지식팩으로 관리하고 생성·상담·검토에 연결합니다.

주요 사용자도메인 전문가 · 지식 관리자 · 현업 사용자

화면 목적

표준·논문·업무지침·과거 산출물을 출처와 승인 상태를 보존한 채 검색하고 재사용합니다.

핵심 기능

  • 지식팩·문서 등록
  • 자연어·근거 기반 검색
  • 검색 품질·원천 레지스트리
  • 프로젝트 문맥 주입

출력

근거 조각, 출처 문서, 적용 범위, 승인·검토 상태, 프로젝트별 참조 묶음.

통제

승인되지 않은 문서와 권한 밖 문서는 LLM 문맥과 검색 결과에서 제외합니다.

업무 흐름원천 등록→검토·승인→검색·근거 선택→생성·판단에 사용

F-06

마스터 데이터

경영 계산과 업무 앱이 공통으로 사용할 기준정보를 버전과 범위로 관리합니다.
