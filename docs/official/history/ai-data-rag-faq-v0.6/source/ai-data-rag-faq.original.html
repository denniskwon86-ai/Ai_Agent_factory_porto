AI LEARNING · DATA PROTECTION · RAG

AI는 어떻게 학습하고,
회사 데이터는 어떻게 보호합니까?

LAXS-M의 현재 구현과 목표 통제를 구분해 설명합니다. 외부 모델의 자율 학습을 주장하지 않으며, 승인된 지식과 업무 결과를 회사가 통제 가능한 형태로 축적하는 것을 우선합니다.

SYSTEM LAXS-MSTATUS Canonical ExplanationVERSION 0.6UPDATED 2026.08.28
단일 정본 AI 학습·외부 LLM 데이터 처리·RAG 구성에 관한 상세 설명은 이 문서에서만 관리합니다. 다른 공식 문서는 독자 역할에 필요한 통제 요약과 이 문서의 참조만 유지합니다.
모델 가중치 온라인 학습현재 사용하지 않음. 업무 결과는 승인 가능한 지식·규칙·스킬 개선안으로 축적합니다.
외부 LLM 완전 비노출그렇게 주장하지 않음. 허용된 최소 문맥만 외부에서 처리하고 기밀 자료는 차단해야 합니다.
문단별 수동 RAG 점수필요하지 않음. 검색 점수는 자동 계산하고 사람은 자료의 정본성과 사용 범위를 승인합니다.
Q1

입력되는 데이터로 강화학습을 합니까?

엄밀한 의미의 온라인 강화학습은 하지 않습니다. LAXS-M은 업무 결과를 감사 가능한 이력으로 축적하고, RAG·프롬프트·업무 규칙·에이전트 스킬의 개선안을 평가·승인한 뒤 버전 단위로 반영합니다.

현재 구현

  • 상호작용·재작업·품질 결과 기록
  • 유사 사례와 승인 지식 검색
  • Persona·Skill 개선안 생성 기반
  • Snapshot·Decision Ledger로 사실과 결정 추적

운영 원칙

  • 실제 데이터가 곧바로 모델 행동으로 굳지 않음
  • 개선 전후를 고정 평가세트로 비교
  • 사람이 승인한 버전만 운영에 승격
  • 향후 미세조정도 승인·비식별 데이터로 제한
업무 데이터→원천·판본 봉인→질문·결정·결과 기록→개선안→평가·승인→새 버전
Q2

유료 외부 LLM을 쓰면서 회사 데이터가 노출되지 않는다고 말할 수 있습니까?

외부 API에 전달한 문맥은 제공자의 시스템에서 처리되므로 “외부 전송 자체가 없다”고 말할 수 없습니다. 대신 기업용 API의 학습 금지 계약과 함께 데이터 등급별 차단·비식별화·최소 전송·보존 통제를 적용해야 합니다.

현재 기반

  • 로컬 벡터 저장소와 로컬 임베딩
  • 전체 문서가 아닌 검색 문맥 사용
  • 조직·부서 범위와 승인 지식 필터
  • 다중 LLM Gateway와 호출 기록 기반

완성해야 할 통제

  • 공개·사내·기밀·제한 등급별 Egress Policy
  • PII·계정·계약·핵심 수치 마스킹
  • 기업용 API·보존기간·ZDR 적용 가능성 확인
  • 외부 전송 원장과 공급자·모델 Allowlist
핵심 구분 “학습에 사용하지 않는다”, “저장하지 않는다”, “외부로 전송하지 않는다”는 서로 다른 보증입니다. 공급자·제품·엔드포인트별 계약과 기술 설정을 각각 확인해야 합니다.
Q3

사람이 수동으로 점수를 매기지 않고 RAG를 어떻게 연결하고 구성합니까?

사람은 자료가 정본인지와 어느 업무·조직에서 사용할지를 승인합니다. 문서 분할, 로컬 임베딩, 유사도 계산, 권한·유효기간 필터, 근거 연결은 시스템이 자동 수행합니다.

자동 수행

  • 문서·업무 데이터의 결정론적 분할
  • 로컬 임베딩과 벡터 색인
  • 질문별 유사 문맥 검색과 기준점 적용
  • 조직·기간·보안·Snapshot 필터
  • 답변 근거와 인용 경로 연결

사람이 책임지는 부분

  • 자료의 원천·정본·보안등급 승인
  • Knowledge Pack의 적용 범위와 유효기간
  • 잘못된 근거의 정정·폐지
  • 중요 정책·스킬·검색 설정의 승격
자료 등록→정본·범위 승인→자동 분할·임베딩→검색·권한 필터→근거 포함 답변→품질 평가
참고: 상용 LLM 정책은 공급자와 계약 유형별로 다릅니다. OpenAI의 비즈니스/API 데이터 학습 기본정책과 보존 통제는 Enterprise Privacy 및 API Data Controls를 기준일 현재 확인했습니다. 실제 도입 시 선택 공급자의 계약·리전·보존·서드파티 연결 정책을 별도 검토해야 합니다.
