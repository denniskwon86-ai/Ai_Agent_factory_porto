# 공급망 지연이 생산·매출에 미치는 영향 판단 기준

> **DEMO/SYNTHETIC · 실제 실적 아님**  
> LAXS-M의 기능 검증과 시연을 위해 구성한 합성 업무 지식입니다. 실제 경영 판단에는 사용할 수 없습니다.

## 1. 이 기준이 답하는 질문

해외 원료 선적이 지연될 때 다음 질문을 같은 근거 사슬에서 판단합니다.

1. 어떤 선적이 계획보다 늦어졌는가?
2. 도착 지연이 어느 원료 재고와 안전재고를 압박하는가?
3. 재고 부족이 어느 생산계획의 실행 가능 물량을 낮추는가?
4. 생산 차질이 어느 판매행의 출하 및 매출 인식 시점을 미루는가?
5. 지금 필요한 조치는 재고 전용, 대체 조달, 생산순서 변경 중 무엇인가?

## 2. 시연 업무 문맥

| 구분 | 합성 사례 |
|---|---|
| 대상 회사 | LS MnM 시연 환경 |
| 대상 조직 | 제련공장 · 사전검증 |
| 원료 | 동정광 `RM-CU-CONC` |
| 제품 | 전기동 `FG-CATHODE` |
| 분석 기준 | 인증판과 승인된 관계만 사용 |
| 데이터 구분 | `SYNTHETIC` / `CERTIFIED_FOR_DEMO` |

## 3. 근거 사슬

다음 네 업무 객체는 각자의 식별자와 인증판을 유지합니다. 문구가 비슷하다는 이유로 자동 연결하지 않습니다.

| 단계 | 업무 객체 | 화면에서 확인할 핵심 정보 |
|---|---|---|
| 물류 | 선적 | 선적번호, 구매행, ETA·ATA, 운송수량 |
| 재고 | 원료 재고 스냅숏 | 위치, 원료, 가용수량, 안전재고 |
| 생산 | 생산계획행 | 제품, 계획수량, BOM 소요량, 우선순위 |
| 판매 | 판매행 | 고객, 납기일, 출하일, 수량, 단가 |

관계는 `선적 → 재고 → 생산계획 → 판매행` 순서로 읽습니다. 각 관계는 원문 근거와 승인 사건을 가져야 하며, 승인 철회 또는 원문 지문 변경 시 더 이상 유효한 경로로 사용하지 않습니다.

## 4. 판단 규칙

### 4.1 도착 지연

- 선적 상태 문자열만으로 도착 여부를 판정하지 않습니다.
- 계획 ETA와 실제 ATA 사건을 대조합니다.
- ATA가 없으면 기준시점 현재 운송 중으로 판단하고, 지연일은 기준시점과 ETA의 차이로 계산합니다.

### 4.2 가용 재고와 부족량

- 가용 재고는 무제한 사용 가능 재고에서 안전재고를 차감해 계산합니다.
- 품질검사·보류·차단 재고는 별도 상태로 유지하며 임의 합산하지 않습니다.
- 생산 소요량은 승인된 BOM과 수율 기준으로 재계산하고, 저장값과 불일치하면 둘 중 하나를 임의 선택하지 않습니다.

### 4.3 생산 영향

- 생산 가능량은 생산계획량을 초과할 수 없습니다.
- 원료가 부족하면 우선순위가 높은 생산계획부터 가용량을 배분합니다.
- 원료·BOM·생산계획 중 하나라도 인증판이 없으면 결과를 0으로 표시하지 않고 `계산 불가`로 처리합니다.

### 4.4 판매·매출 영향

- 실제 납기 지연과 시나리오상 매출 이연을 구분합니다.
- 생산계획과 판매행의 연결 근거가 없으면 영향 없음으로 처리하지 않습니다.
- 결과에는 사용한 인증판, 관계 승인 사건, 계산 판본, 기준시점을 함께 남깁니다.

## 5. 시연 의사결정 예시

LAXS-M은 아래와 같은 형태로 경영 판단 후보를 제시해야 합니다.

- **관찰:** 동정광 선적 도착 지연과 원료 가용재고 부족이 동시에 발생했습니다.
- **영향:** 우선순위가 낮은 생산계획의 실행 가능 물량이 감소하고 연결 판매행의 출하 시점이 늦어질 수 있습니다.
- **선택지 A:** 다른 창고·사업장 재고를 전용하되 품질·운송 리드타임을 다시 검증합니다.
- **선택지 B:** 대체 조달을 실행하고 추가 운임과 납기 회복 효과를 함께 비교합니다.
- **선택지 C:** 생산순서를 조정해 기여이익 또는 고객 우선순위가 높은 판매행을 먼저 보호합니다.
- **필수 확인:** 데이터 소유자 승인, 관계 승인, 계산 능력 승인, 재무 영향 재검증.

## 6. 사용 제한

이 문서는 합성 시연 자산입니다. 실제 운영 전에는 다음을 완료해야 합니다.

1. 현업 Data Owner가 산식·단위·안전재고 정책을 검토합니다.
2. 실제 Source Binding과 대사 완료 증거를 연결합니다.
3. 실제 조직 범위와 승인자를 확정합니다.
4. 산식 계약과 계산 능력을 정식 승인합니다.
5. 결과를 실제 경영 판단에 사용하기 전 백테스트와 사용자 검증을 수행합니다.
