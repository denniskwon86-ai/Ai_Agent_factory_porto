# AI Factory Studio 제품 브로셔

## 파일

- `index.html`: 화면·인쇄 겸용 12면 제품 브로셔
- `styles.css`: LS 계열 색상과 승인된 Living Enterprise Canvas를 반영한 스타일
- `brochure.js`: 원료 도입 지연·가격 시나리오의 브로셔용 상호작용
- `assets/actual/`: 현재 구현 서버에서 직접 캡처한 실제 제품 화면 4종

## 보는 방법

PowerShell에서 저장소 루트를 기준으로 다음을 실행한다.

```powershell
python -m http.server 8090
```

브라우저에서 다음 주소를 연다.

```text
http://127.0.0.1:8090/docs/product-brochure/
```

오른쪽 위 `PDF로 저장`을 누르면 16:10 가로 12면 PDF로 인쇄할 수 있다. 인쇄 옵션에서는 배경 그래픽을 켜고, 페이지 크기는 CSS가 제안하는 사용자 정의 크기를 유지한다. A4를 수동으로 강제하면 화면용 고정 배치가 다시 계산되어 도식과 실제 화면이 잘릴 수 있다.

검증된 PDF는 저장소의 `output/pdf/AI_Factory_Studio_Product_Brochure_2026-08-13.pdf`에도 생성한다.

## 표현 원칙

- 제품 범주: `Manufacturing Management Twin & Operational App Factory`
- 제품 정체성: 실제 데이터 → 현업 앱 → 결정론적 시뮬레이션 → 의사결정 → 실행 → 효과 측정 폐루프
- 현재 구현과 목표 상태를 혼동하지 않기 위해 구체적인 고객 효과 수치를 임의로 사용하지 않는다.
- 5~8면은 2026-08-13 현재 구현된 실제 제품 화면이며, 각 면에 `현재 구현 화면`과 `LIVE PRODUCT`를 표시한다.
- 실제 화면에 표시되는 계정·테넌트·프로젝트·수치는 개발 환경의 예시 데이터이며 고객 실적이 아니다.
- 첫 증명 시나리오는 원료 구매·도입 지연에서 생산·매출·현금흐름까지의 수직 폐루프다.
- LS 색상은 현재 기업 테마 예시다. 상용화 시 고객사 CI 테마로 치환한다.
- 화면의 회사명과 수치는 가상의 설명용 데이터다.
