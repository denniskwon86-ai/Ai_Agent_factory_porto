## 0. 왜 여쭙나

### 저희가 만들고 있는 것

AX 업무 플랫폼에 **업무키트**를 얹고 있습니다. 「이 산업은 보통 이런 품목·공정·
데이터로 일한다」를 **미리 채워 드리는 한 벌**입니다. 그래야 현업이 처음 열었을 때
「우리 업무 중 어디에 어떻게 쓰겠다」를 빨리 잡을 수 있습니다.

**전지소재 사업만 담은 키트**를 따로 냈습니다 — 전지소재만 하는 회사에도 그대로
드릴 수 있게 하려는 것입니다.

### 저희가 채우는 것과 채우지 않는 것

| | |
|---|---|
| **저희가 채웁니다** | 그 **산업이면 대체로 그런 것** — 품목 흐름, 공정 순서, 무엇이 손익을 움직이는가 |
| **채우지 않습니다** | **회사 특성·경영방침** — 조직 편제, 실제 단가, 거래 조건. 현업이 플랫폼 안에서 쌓으실 몫입니다 |

### 그래서 여쭙습니다

| | 여쭙는 것 | 급한가 | 무엇이 걸려 있나 |
|---|---|---|---|
| **1** | **무엇이 손익을 움직이나** | **★ 가장 급함** | **저희가 아직 모릅니다** — 제련과 달리 초안조차 없습니다 |
| **2** | **저희가 이미 이상하다고 보는 것** | **★ 급함** | 셋을 찾았습니다. 숨기지 않고 함께 여쭙습니다 |
| 3 | 지금 넣어 둔 값 | 보통 | 데이터를 열면 바로 보이는 숫자입니다 |
| 4 | 신규 사업 램프업 | 보통 | 실적이 없는 사업을 그리려면 필요합니다 |

## 1. ★ 무엇이 손익을 움직이나 — **저희가 모릅니다**

> 「이것이 1% 변하면 손익이 얼마나 변하는가」를 묻는 항목입니다. 시나리오
> (「니켈 가격이 20% 오르면?」)의 재료가 됩니다.

### 지금 어떻게 돼 있나

키트에 「무엇이 손익을 움직이는가」를 12 가지로 담고 있는데 **전부 범용 제조업의
것**입니다.

    환율 · 원자재가격 · 운임 · 납기지연 · 공급 · 수율 · 설비정지
    전력단가 · 수요 · 투자 · 매출총이익 · 현금

실제로 돌려 보니 **제련 키트와 전지소재 키트가 완전히 같은 11 개**를 냅니다. 즉
**사업이 달라도 나오는 것이 같습니다.**

### ⚠️ 제련은 짐작이 되는데 전지소재는 모릅니다

제련은 「제련수수료(TC/RC)·회수율·부산물이 손익을 가른다」고 이해했습니다. 그런데
**전지소재는 무엇인지 저희가 모릅니다.** 지어내지 않고 여쭙습니다.

    전지소재에서 손익을 가르는 것은 무엇입니까?

### 저희가 떠올린 후보 — **틀렸으면 지워 주십시오**

⚠️ 아래는 **확신이 아니라 추측**입니다. 「이건 아니다」를 짚어 주시는 것만으로도
  큰 도움입니다.

| | 후보 | 왜 그렇게 생각했나 | **맞습니까** | 보통 어느 범위입니까 |
|---|---|---|---|---|
| ① | **니켈 가격 전가** | 원료(MHP)도 제품(황산니켈)도 니켈 시세를 타는데, **전가되는 비율**이 손익을 가르지 않을까 | ☐ | |
| ② | **원료 조달 조건** | 스팟이냐 장기계약이냐, 그리고 MHP 의 **Ni 함량(품위)** | ☐ | |
| ③ | **배터리급 수율·불순물** | 규격을 못 맞추면 도금용·촉매용으로 훨씬 싸게 나간다고 들었습니다 | ☐ | |
| ④ | **고객 인증 단계** | 양극재사 승인 전에는 매출이 없다 | ☐ | |
| ⑤ | **전환비(가공비)** | 제련의 TC/RC 에 해당하는 것이 있습니까 | ☐ | |

| 함께 여쭙는 것 | 답 |
|---|---|
| **위에 없는데 중요한 것**이 있습니까 | |
| **무엇이 가장 크게 움직입니까** (하나만 고르신다면) | |
| 황산니켈과 수산화리튬이 **서로 다른 동인**을 탑니까 | |

## 2. ★ 저희가 이미 이상하다고 보는 것 — 셋

숨기지 않고 함께 여쭙습니다.

### 2.1 ★★★ 수산화리튬을 만드는데 **리튬이 안 들어갑니다**

지금 배합이 이렇습니다.

    수산화리튬 1 톤  ←  황산 0.12 톤  +  소석회 0.05 톤

**리튬 원료가 없습니다.** 저희가 잘못 넣은 것으로 보입니다.

| | 답 |
|---|---|
| 실제로는 **무엇이 들어갑니까** (탄산리튬? 리튬정광? 염수?) | |
| 대략 **얼마나** 들어갑니까 (수산화리튬 1 톤당) | |
| 애초에 **이 제품을 키트에 넣는 것이 맞습니까** — 황산니켈과 공정이 많이 다르면 빼는 편이 나을 수도 있습니다 | |

### 2.2 매출이 **수산화리튬 쪽이 더 큽니다**

    수산화리튬  57.2%
    황산니켈    42.8%

저희는 이 키트를 **「전지소재(황산니켈)」**로 이름 붙였는데, 정작 매출은 리튬이
큽니다. 이름과 내용이 어긋납니다.

| | 답 |
|---|---|
| 실제 비중은 어느 쪽이 큽니까 | |
| 키트 이름을 **무엇으로 부르는 것이 맞습니까** | |

### 2.3 황산니켈이 **전기동보다 비쌉니다**

같은 회사의 제련 제품과 견주면 지금 데이터에서 이렇습니다.

| | 지금 | **맞습니까 / 실제 관계는** |
|---|---|---|
| 전기동 vs 고순도 황산니켈 | 황산니켈이 **2.5 배 비싸다** | |

⚠️ 이것이 틀리면 **매출 구성과 손익이 통째로 어긋납니다.** 다만 고치면 재무 데이터
  전체가 딸려 움직이므로, 확인을 받고 한 번에 바로잡으려 합니다.

## 5. 답을 어떻게 주시면 되나

**표의 빈칸만 채워 주셔도 됩니다.** 형식은 상관없습니다 — 메일·메모·구두 모두
좋습니다.

| 이렇게 답해 주시면 가장 좋습니다 | |
|---|---|
| **틀린 것** | 「이건 아니다」만 짚어 주셔도 큰 도움입니다 |
| **범위** | 정확한 값이 아니라 **보통 어느 정도인지**면 충분합니다 |
| **모르시는 것** | 「모른다」도 답입니다 — 저희가 비워 둡니다 |

⚠️ **회사 실제 수치를 주실 필요는 없습니다.** 업계에서 통상 어느 정도인지면 됩니다.
  회사 특성·경영방침에 해당하는 것은 키트에 담지 않습니다.

### 넷을 다 답하지 않으셔도 됩니다

| 이만큼만 주셔도 | 저희가 할 수 있는 것 |
|---|---|
| **1 장만** (손익을 움직이는 것) | 키트가 **전지소재답게** 됩니다 — **가장 큰 진전입니다** |
| **2 장만** (이상한 것 셋) | **틀린 데이터를 바로잡습니다** — 특히 리튬 배합 |
| 3 장 | 데이터를 열었을 때 보이는 숫자까지 맞습니다 |
| 4 장 | 신규 사업(배터리소재)을 그릴 수 있습니다 |

★ **1 장은 「맞다 / 아니다」 체크만으로도 충분합니다.**

⏱ 1 장만이면 **10 분**, 전부면 **30 분** 정도로 보고 있습니다.
