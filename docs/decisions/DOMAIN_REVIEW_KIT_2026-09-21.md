## 0. 왜 여쭙나

### 저희가 만들고 있는 것

AX 업무 플랫폼에 **업무키트**를 얹고 있습니다. 「이 산업은 보통 이런 품목·공정·
데이터로 일한다」를 **미리 채워 드리는 한 벌**입니다. 그래야 현업이 처음 열었을 때
「우리 업무 중 어디에 어떻게 쓰겠다」를 빨리 잡을 수 있습니다.

### 저희가 채우는 것과 채우지 않는 것

| | |
|---|---|
| **저희가 채웁니다** | 그 **산업이면 대체로 그런 것** — 품목 흐름, 공정 순서, 무엇이 손익을 움직이는가 |
| **채우지 않습니다** | **회사 특성·경영방침** — 조직 편제, 실제 단가, 거래 조건. 이것은 현업이 플랫폼 안에서 쌓으실 몫입니다 |

### 그래서 여쭙습니다

지금 키트에 **저희가 공개 지식으로 써 넣은 값**이 있습니다. 구조는 맞다고 보지만
**수치는 회사·계약마다 다릅니다.** 틀린 채로 두면 데이터를 열어 보신 분이 「우리
얘기가 아니다」라고 느끼고, 그러면 키트를 드리는 뜻이 없어집니다.

| 물음 | 급한가 | 무엇이 걸려 있나 |
|---|---|---|
| **1. 제련에서 무엇이 손익을 움직이나** | **★ 가장 급함** | 이것이 없으면 키트가 **범용 제조업**과 같습니다 |
| **2. 지금 넣어 둔 값** | ★ 급함 | 데이터를 열면 바로 보이는 숫자입니다 |
| 3. 신규 사업 램프업 | 보통 | 배터리소재처럼 **실적이 없는 사업**을 그리려면 필요합니다 |

## 1. ★ 제련에서 무엇이 손익을 움직이나 — 가장 급합니다

> 저희는 이것을 **「동인(動因)」**이라 부릅니다 — 「이것이 1% 변하면 손익이 얼마나
> 변하는가」를 묻는 항목입니다. 시나리오(「TC/RC 가 20% 떨어지면?」)의 재료가 됩니다.

### 지금 어떻게 돼 있나

키트에 「무엇이 손익을 움직이는가」를 12 가지로 담고 있습니다. 그런데 **전부 범용
제조업의 것**입니다.

    환율 · 원자재가격 · 운임 · 납기지연 · 공급 · 수율 · 설비정지
    전력단가 · 수요 · 투자 · 매출총이익 · 현금

★ **제련사는 금속 가격으로 벌지 않는다**고 알고 있습니다. 가격은 헤지로 중립화하고
**제련수수료·회수율·부산물**이 손익을 가른다고 이해했습니다. 그런데 그 셋이 위
목록에 **하나도 없습니다.**

#### 실증 — 제련 키트와 전지소재 키트가 **똑같습니다** (2026-09-21)

키트의 동인을 플랫폼으로 옮기는 연결을 만들어 실제로 돌려 봤습니다.

    제련 키트      → 동인 11 개
    전지소재 키트  → 동인 11 개   ← **완전히 같은 11 개**

즉 **사업이 달라도 나오는 것이 같습니다.** 위 12 가지가 범용 제조업의 것이기
때문입니다. 이 답을 주셔야 「제련 키트」가 제련다워집니다.

### 여쭙는 것

| | 넣으려는 것 | 저희 이해 | **맞습니까** | 보통 어느 범위입니까 |
|---|---|---|---|---|
| ① | **제련수수료 (TC/RC)** | 제련사 수익의 본체. 연 단위 벤치마크 협상으로 정해지고, 광산 공급이 늘면 오르고 제련 능력이 늘면 내린다 | ☐ | |
| ② | **금속 회수율** | 정광에 든 금속 중 실제로 뽑아내는 비율. 1%p 차이가 손익을 가른다 | ☐ | |
| ③ | **정광 품위** | 산지·광체별로 다르고, 품위가 낮으면 같은 톤수로 금속이 덜 나온다 | ☐ | |
| ④ | **부산물 크레딧** | 황산·금·은. 부수입이 아니라 **손익 구조의 일부** | ☐ | |
| ⑤ | **지역 프리미엄** | LME 위에 얹히는 현물 프리미엄. 지역·형태별로 다르다 | ☐ | |

### 함께 여쭙고 싶은 것

| | |
|---|---|
| **다섯이 맞습니까** | 빠진 것이 있습니까. 반대로 **넣을 필요가 없는 것**이 있습니까 |
| **무엇이 가장 크게 움직입니까** | 하나만 고르신다면 |
| ②와 기존 「수율」의 차이 | 저희는 **생산 수율**과 **금속 회수율**을 다른 것으로 보았습니다 — 맞습니까 |

## 2. ★ 지금 데이터에 넣어 둔 값 — 열면 바로 보입니다

### 2.1 품목 등급

등급 **체계가 있다**는 것은 확실하다고 보았습니다. 값이 맞는지 봐 주십시오.

| 품목 | 지금 넣은 값 | 저희 근거 | **맞습니까 / 고칠 값** |
|---|---|---|---|
| 동정광 | `CU_25PCT` | Cu 25% 내외가 표준 거래 품위 | |
| 동 매트 | `CU_60PCT` | | |
| 아노드동 | `CU_99_5PCT` | | |
| **전기동** | `LME_GRADE_A` | LME 등록 등급(Cu 99.99%) | |
| 부산물 황산 | `TECHNICAL_98PCT` | 공업용 98% | |
| 부산물 금 | `FINE_GOLD_9999` | 순금 99.99% | |
| 니켈 MHP | `NI_40PCT` | Ni 35~40% 가 통상 | |
| **고순도 황산니켈** | `BATTERY_GRADE` | 양극재사 규격 통과 여부로 갈린다 | |

⚠️ 실제로 이런 이름으로 부르십니까. **현장에서 쓰는 표기**가 따로 있으면 그것이
  훨씬 낫습니다.

### 2.2 부산물이 얼마나 나오는가

전기동 **1 톤**을 뽑을 때 함께 나오는 양으로 이렇게 넣었습니다.

| 부산물 | 지금 넣은 값 | **맞습니까 / 고칠 값** |
|---|---|---|
| 황산 | **3.0 톤** | |
| 금 | **0.010 kg** (10 g) | |

그 결과 지금 키트의 제련 매출 구성이 이렇습니다.

    전기동   85.1%
    금       13.8%
    황산      1.1%

| 여쭙는 것 | |
|---|---|
| **이 비중이 실제와 비슷합니까** | 크게 어긋나면 「부산물로 번다」가 데이터로 안 보입니다 |
| 은은 왜 없습니까 | 저희가 금만 넣었습니다. **은도 넣어야 합니까** |

### 2.3 판매 단가

⚠️ 지금 단가는 **데모용 척도**이고 절대값에 뜻이 없습니다. 다만 **서로의 비율**은
맞아야 합니다.

| | 지금 비율 | **맞습니까** |
|---|---|---|
| 전기동 : 황산 | 약 **240 : 1** | |
| 전기동 : 금(kg) | 약 **1 : 8.3** (금 1 kg 이 전기동 8.3 톤) | |

### 2.4 ★ 저희가 이미 이상하다고 보는 것

숨기지 않고 함께 여쭙습니다. 지금 데이터에서 **황산니켈이 전기동보다 비싸게**
매겨져 있는데, 저희가 알기로 실제는 반대입니다.

| | 지금 | **맞습니까 / 실제 관계는** |
|---|---|---|
| 전기동 vs 고순도 황산니켈 | 황산니켈이 **2.5 배 비싸다** | |

⚠️ 이것이 틀리면 **매출 구성과 손익이 통째로 어긋납니다.** 다만 고치면 재무 데이터
  전체가 딸려 움직이므로, 확인을 받고 한 번에 바로잡으려 합니다.

## 4. 답을 어떻게 주시면 되나

**표의 빈칸만 채워 주셔도 됩니다.** 형식은 상관없습니다 — 메일·메모·구두 모두
좋습니다.

| 이렇게 답해 주시면 가장 좋습니다 | |
|---|---|
| **틀린 것** | 「이건 아니다」만 짚어 주셔도 큰 도움입니다 |
| **범위** | 정확한 값이 아니라 **보통 어느 정도인지**면 충분합니다 |
| **모르시는 것** | 「모른다」도 답입니다 — 저희가 비워 둡니다 |

⚠️ **회사 실제 수치를 주실 필요는 없습니다.** 업계에서 통상 어느 정도인지면 됩니다.
  회사 특성·경영방침에 해당하는 것은 키트에 담지 않습니다.

### 셋을 다 답하지 않으셔도 됩니다
