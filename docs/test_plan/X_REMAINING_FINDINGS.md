## X-1 판정표 — 단계에 안 붙는 도메인을 어떻게 봤나

| 도메인 | 판정 | 근거 |
|---|---|---|
| `/` | 기반시설 | 정적 진입점 |
| `/api/v1/simulations` | 기반시설 | 시뮬레이션 실행 id 로 결정 안건을 거는 접합부. 7단계(비교)와 8단계(의사결정) «사이»라 한쪽에 못 붙인다 |
| `/docs` | 기반시설 | API 문서 화면. 도구용이다 |
| `/health` | 기반시설 | 가동 확인. 흐름에 안 붙지만 없으면 배포·감시가 못 선다 |
| `/openapi.json` | 기반시설 | API 명세. 도구용이다 |
| `/redoc` | 기반시설 | API 문서 화면. 도구용이다 |
| `/skills` | 기반시설 | 에이전트 스킬 제안의 사람 승인 관문(승인·거부). 8단계가 아니라 플랫폼 자기 진화를 다룬다. 없으면 AI 제안이 승인 없이 반영된다 — X-3 참조 |
