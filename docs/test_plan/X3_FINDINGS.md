## 판정

### X-3 **통과** — 세 경로가 전부 막혀 있다

★ 수용 기준의 핵심은 「막혔다」가 아니라 **「막는 것이 결정론적 검증기인가」** 다.
  위 항목은 전부 **대조표·정규식·필수 인자**가 막았다 — 프롬프트의 지시가 아니다.
  LLM 에게 「지어내지 마라」고 적는 것은 차단기가 아니다. 같은 프롬프트가 다음에 다른 답을 낼 수 있고, 그때 아무도 모른다.

⚠️ 이 결과가 «주장하지 않는» 것

- LLM 을 **실제로 부르지 않았다.** 「이 관문들이 LLM 출력 모양을 막는다」까지가 주장이다.
- ③ 은 **정적 조사**다. 소스에 창구가 없다는 것이지 런타임에 플러그인·의존 라이브러리가 무엇을 하는지는 여기서 알 수 없다.
- 화면이 LLM 제안을 **사람에게 확인시키는지**는 Codex 레인이다.
