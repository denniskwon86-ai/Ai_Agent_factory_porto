# AI Factory Studio 제품 및 기능소개서

기존 제품 브로셔(`docs/product-brochure/`)를 변경하지 않고 별도로 만든 상세 기능소개서입니다.

## 문서 구성

- 1~7면: 제품 특성, 제품 정의, 7대 기능, 폐루프, 엔터프라이즈 신뢰 모델, 기능 지도
- 8면: 실제 프로그램 기능소개 파트 구분
- 9~21면: 현재 구현 화면 기반 13개 기능소개
- 22면: 현재 구현 기반과 제품 완성을 위한 다음 증명
- 23면: 마무리

각 기능 페이지는 `화면 목적 → 핵심 기능 → 출력 → 통제 → 업무 흐름` 순으로 읽을 수 있습니다.

## 열람

저장소 루트에서 정적 서버를 실행한 뒤 아래 주소를 엽니다.

```powershell
python -m http.server 8092
```

```text
http://127.0.0.1:8092/docs/product-feature-guide/
```

브라우저 폭이 1,440px보다 작으면 화면에 맞게 자동 축소됩니다. PDF 출력에서는 15×9.375인치 16:10 판형을 그대로 사용합니다.

## PDF

- 검증 완료 파일: `output/pdf/AI_Factory_Studio_Product_Feature_Guide_2026-08-13.pdf`
- 검증 결과: 23면, 1080×675.12pt, 텍스트 포함, 전체 페이지 PNG 재렌더 확인

브라우저 우측 상단 `PDF로 저장` 버튼으로 다시 출력할 수 있습니다. 배경 그래픽을 켜고 CSS가 제안하는 페이지 크기를 사용해야 합니다.

## 상태 표기와 주의사항

- `ACTUAL PRODUCT SCREEN`: 현재 실행 중인 제품에서 직접 캡처한 화면
- `PRODUCT DIRECTION`: 최종 제품 방향 또는 고도화 범위
- 화면 속 수치와 프로젝트는 검증용 예시 데이터이며 고객 운영 실적이 아닙니다.
- 실제 경영 현장 적용 전 Host Runtime, 데이터 기준선, 온톨로지, 계산 그래프, Shadow Pilot 종단 검증이 필요합니다.
- 화면에 남아 있는 `Jarvis`는 개발 가칭입니다. 공식 문서에서는 `AI 경영비서` 또는 실제 화면 기능명으로 표기하며, 정식 고유명은 별도 승인 후 제품과 문서에 함께 적용합니다.
