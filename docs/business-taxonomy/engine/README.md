# 판정 엔진

> ⚠️ **검토 중 — 확정된 설계가 아니다.** 현재 시스템에 연결·연계하지 않는다.
> 자세한 조건은 [../README.md](../README.md).

**AI 가 매번 판정하지 않도록** KSIC 코드에서 A·B 축을 규칙으로 판정한다.

## 구성

| 파일 | 역할 |
|---|---|
| `ksic_rules.py` | **법인 판정** — KSIC → (A 업태, B 업종, B 2단) 매핑 + 모수·묶음 판정 |
| `segment_rules.py` | **세그먼트 판정** — 영업부문명 → 축. 법인 1건을 사업 n 건으로 나눈다 |
| `fetch_ftc.py` | **수집기** — 공정위 소속회사를 받아 판정까지 붙인다. `dedupe()` 로 유일화한다 |
| `fetch_dart.py` | **세그먼트 수집기** — DART 주석 파일을 골라낸다. `to_ksic()` 로 업종코드도 얻는다 |
| `parse_segment.py` | **세그먼트 파서** — 주석의 영업부문 표에서 부문명·주요제품·매출 |
| `build_universe.py` | **통합 모수** — 공정위 + 상장 법인을 법인등록번호로 이어 셀 분포를 낸다 |
| `collect_segments.py` | 상위 셀 회사의 부문을 수집한다(지주회사 + 매출 상위) |
| `apply_segments.py` | 다부문 회사를 부문으로 대체해 인스턴스 목록을 만든다 |
| `fetch_unlisted.py` | **비상장 공시법인 수집기** — 르노코리아처럼 상장이 아닌 실체를 담는다 |
| `dump_datasets.py` | 수집 데이터를 `samples/` 에 남긴다 — `.cache/` 는 커밋되지 않는다 |
| `make_dashboard.py` + `dashboard.tpl.html` | **산업 커버리지 맵** — 격자에서 사업묶음을 고르고 롱리스트를 뽑는다 |

## 쓰는 법

```bash
python fetch_ftc.py ALL affiliates.csv
```

기업집단 코드를 주면 그 집단만 받는다(엘지 `K1000051`, 에스케이 `K1000050`,
현대자동차 `K3000027`, HD현대 `K3000052`, 신세계 `K1000042`).

판정만 따로 쓰려면:

```python
from ksic_rules import classify
classify('C2020', 18216499)   # → 소재제조 / 화학·소재 / 석유화학·기초
classify('K6499', 884989)     # → 지주·투자 / 다품목·범용, 묶음노드 Y
classify('L6821', 0)          # → 모수밖 (매출 0)
```

## 판정 순서

규칙이 매핑보다 앞선다.

| 순서 | 규칙 | 근거 |
|---|---|---|
| ① | **매출 0 → 모수 밖** | 사업 실질이 없는 껍데기. SPC·청산·준비 단계 |
| ② | **KSIC `K6499`·`M7151` → 지주·투자 + 묶음 노드** | 그 매출이 모수 안 다른 인스턴스 매출을 포함한다 |
| ③ | KSIC 매핑 (5 → 4 → 3 → 1자리) | 긴 접두사 우선. 중분류에서 대부분 결정된다 |
| ④ | 못 찾으면 **미판정** | 억지로 채우지 않고 사람이 본다 |

판정 결과는 [../samples/ftc-all-2026-classified.csv](../samples/ftc-all-2026-classified.csv) 에 있다.

**사람 판정과 대조**

| 대상 | 방식 | 결과 |
|---|---|---|
| LG 63개사 | 전수 대조 | **98% (62/63)** |
| SK 151 + 현대차 74 | **KSIC 별 검수** | 보완 지점 8곳 발견 → 규칙 반영 |

⚠️ SK·현대차는 **전수 대조가 아니라 KSIC 별 검수**다. 같은 KSIC 는 같은 판정을 받으므로
코드 종류만큼만 보면 되지만, 법인별 실질 차이는 이 방식으로 못 잡는다.

남은 1건은 `C2842`(조명장치 제조업)로, KSIC 만으로는 **차량용 부품인지 일반 조명 완제품인지
갈리지 않는다.** 규칙으로 100% 를 만들 수 없고 이 정도가 현실적 상한이다 —
**나머지는 사람이 검토한다.**

## 규칙을 고치는 방법

1. 사람 판정과 대조해 불일치를 찾는다
2. `MAP` 에 **더 긴 접두사**로 예외를 추가한다 (짧은 규칙은 그대로 둔다)
3. 다시 대조한다

LG 전수 대조에서 95% → 98% 가 됐고, SK·현대차 검수에서 8곳을 더 보완했다.
보완 후 LG 재대조에서 **회귀 없이 98% 를 유지**했다.

| 보완한 것 | 이유 |
|---|---|
| `R9119` → 인적서비스 | 스포츠단은 선수 활동이 본체. `R91`(골프장) 은 시설 운영 |
| `S9531` → 전자·정밀 | 가전 수리. `S9521`(자동차 수리) 과 대상이 다르다 |
| `C2842` → 전자·정밀 | 조명장치는 전기·전자 제품 |
| `C2411~2422` → 금속 2단 | 철강 / 강관·형강·선재 / 비철금속 |
| `C3120` → 철도·특수차량 | `C31` 폴백(항공·우주·방산)이 철도차량에 붙었다 |
| `G4731`·`G4771` → 전자·정밀 / 에너지 | 휴대폰 판매 · 주유소가 `다품목·범용` 으로 갔다 |
| `N7629` → 생활용품·가구 | `N76` 폴백(기계·운송기기)이 가전 렌탈에 붙었다 |
| `M7011` → 의약·바이오 | **신약개발사가 「자연과학 연구개발업」으로 신고한다** |

## 세그먼트 분할 — `segment_rules.py`

법인 1건을 **사업 n 건**으로 나눈다. 삼성전자를 DS/DX/SDC/Harman 으로 가르는 일이다.

### 왜 별도 규칙인가

**세그먼트에는 KSIC 가 없다.** 사업보고서에 이름과 매출만 실린다.
법인은 KSIC 로 판정하지만 세그먼트는 **이름으로 판정할 수밖에 없다.**

### 판정 순서

| 순서 | 규칙 |
|---|---|
| ① | **지역 세그먼트는 버린다** (국내/북미/유럽…) — 사업 구분이 아니다 |
| ② | **회사 고유 약어** — 삼성전자 `DS`·`SDC`, LG전자 `HS`·`VS` 등 |
| ③ | **짧은 약어는 정확 일치만** — `IT`·`WM`·`IB`. 부분 일치를 허용하면 「IT」가 「DIGITAL」에 걸린다 |
| ④ | **키워드 사전** — 「석유화학」「배터리」「할인점」… 긴 키워드 우선 |
| ⑤ | 없으면 **모법인 판정을 상속**하고 `상속` 으로 표시 |

키워드가 A 축까지 바꾸는 경우가 있다 — 현대자동차 「금융」 부문은 모법인이 제조여도
`금융` 이 된다. 반대로 「석유화학」은 B 만 바꾸고 A 는 모법인을 따른다.

### 수집기를 붙여 실측했다 — 미판정 54% 에서 6% 로

`parse_segment.py` 가 뽑은 **37 개사 112 개 부문**을 그대로 통과시켰다. 손으로 만든
예시가 아니라 실제 공시에서 나온 이름들이다. 첫 실측은 **미판정 54%** 였다.

원인이 네 갈래였다.

| 원인 | 건수 | 대응 |
|---|---|---|
| **회사명 표기가 달라 약어 사전이 통째로 죽었다** | 10 | 공정위는 「엘지전자」, DART 는 「LG전자」다. 한글 표기를 영문으로 모아 견준다 |
| 키워드 사전에 없는 산업 용어 | 20 | 전력·자동화·금속·동제련·중간재·컴포넌트·광학솔루션·유통업·식량소재·발포제 등을 채웠다 |
| 금융 세부 부문 | 17 | 이름이 업종을 분명히 말하는 것만 넣었다(위탁매매·운용업·개인고객). 깊게 파지 않는다 |
| **부문명이 계열사명이다** | 6 | 아직 못 푼다 — 아래 참조 |

오판정도 둘 잡았다. LG화학 「LG에너지솔루션」이 「에너지」 키워드에 걸려
`에너지·자원·환경` 이 됐는데 배터리 회사이므로 `전지·전원부품` 이다. 이마트 「식음료업」은
「음료」에 걸려 제조로 판정됐지만 외식사업이라 음식점업(I56)과 같은 값을 써야 한다.
**둘 다 짧은 키워드가 긴 이름의 일부를 삼킨 것이다.**

결과는 키워드 68% · 약어 22% · 지역 제외 4% · 미판정 6% 다.

#### 계열사 조인 — 부문명이 계열사명일 때

**순수 지주회사는 부문이 곧 계열사다.** SK 의 부문은 SK이노베이션·SK텔레콤·SKC 다.
이름이 업종을 말하지 않으므로 키워드로는 풀 수 없다. 그래서 공정위 원천 3,539 개사와
이름으로 조인해 **그 법인의 판정을 가져온다**(`affiliate_index()`).

**같은 기업집단 안에서만 찾는다.** 후보가 151 개로 좁아져 오탐이 줄고, 지주회사의
부문은 실제로 그 집단 계열사다.

표기를 맞추는 게 일이다. 부문명은 「SKC」인데 공정위는 「에스케이씨(주)」로 쓴다.
알파벳 한 글자를 한글로 적은 것이라 **끝에 오는 한 글자만** 되돌린다 — 중간까지
바꾸면 「에스케이이노베이션」의 「이」가 E 로 변해 망가진다. 「SK스퀘어(주1)」처럼
각주가 붙어 오는 것도 떼어낸다.

순서는 **키워드가 먼저, 조인이 나중**이다. 조인은 신고 KSIC 를 물려받기 때문이다.

| 부문명 | 공정위 KSIC | 조인 결과 | 실질 |
|---|---|---|---|
| SK텔레콤 | J6122 무선·위성통신 | 시설·자산운영 / 통신·네트워크 | ✔ |
| SK네트웍스 | G4652 가전·통신장비 도매 | 도매·상사 / 다품목·범용 | ✔ |
| SK스퀘어 | K6499 그 외 기타 금융업 | 지주·투자 / 다품목·범용 | ✔ 투자 지주다 |
| **SK이노베이션** | K6499 | 지주·투자 | ✘ 에너지·화학인데 성격을 잃는다 |
| **SKC** | K6499 | 지주·투자 | ✘ 화학·소재인데 성격을 잃는다 |

**조인의 한계가 여기 있다.** 지주회사 체제 계열사는 개별 KSIC 가 K6499 이고 실제
사업은 그 아래 자회사에 있다. SK 부문 표의 「SK이노베이션」 매출은 80 조인데 공정위
개별 매출은 4.9 조다 — **부문은 연결, 공정위는 개별**이라 자릿수가 다르다.
그래도 미판정보다는 낫고, 판정근거에 `계열사 「…」` 가 남아 되짚을 수 있다.

LS 「부품」·「글로벌」은 성격이 다르다. 이름이 추상적이라 사람도 판정할 수 없다.
**미판정이 정답이다.** 미판정은 7 건에서 2 건(2%)으로 줄었다.

### 예시

```
(주)엘지화학 [C2020] → 소재제조 / 화학·소재
   / 석유화학    소재제조  화학·소재     석유화학·기초   키워드
   / 첨단소재    소재제조  화학·소재     전자·전지소재   키워드
   / 생명과학    소재제조  의약·바이오               키워드

현대자동차(주) [C3012] → 완제품제조 / 기계·운송기기
   / 차량       완제품제조 기계·운송기기  완성차·부품    키워드
   / 금융       금융      금융                    키워드 (A 축까지 바뀐다)
   / 국내·북미                                    지역 — 제외
```

### 기업 → 산업분류, 어디서 얻나

판정의 입력은 KSIC 다. 그런데 **어디서 받느냐에 따라 덮는 범위가 다르다.**
공개 자료를 훑어 정리했다.

| 출처 | 범위 | KSIC | 조인 키 | 한계 |
|---|---|---|---|---|
| **공정위 기업집단포털** | 대기업집단 소속 3,539 개사 | 4~5자리 | 법인등록번호·사업자등록번호 | **비집단 기업이 없다.** 이 중 상장은 390 개뿐 |
| **DART 기업개황** | 모든 공시법인 | 3~5자리(복원 필요) | 고유번호·종목코드·**법인등록번호** | 자릿수가 신고 수준을 따라 세분류가 흔들린다 |
| KRX 업종분류 (`data.krx.co.kr` [12025]) | 상장 전체 | 거래소 부여 | 종목코드 | **로그인이 필요하다** — 자동 수집이 막힌다 |
| 공공데이터포털 KRX상장종목정보 | 상장 전체 | 없음 | 법인등록번호 | 업종을 주지 않는다. **조인 키로만** 쓸 값이다 |
| KOSIS 전국사업체조사 | 전체 사업체 | 5단계 | — | 집계 통계라 개별 기업이 없다 |
| NICE·KED·FnGuide | 150 만 기업 | 있음 | — | 상용이다 |

**결론은 두 갈래로 쓰는 것이다.** 대기업집단 소속은 공정위가 낫고(재무·종업원수까지 온다),
그 밖은 DART 가 유일한 경로다.

#### 법인등록번호로 잇는다 — `resolve_ksic()`

**이름으로 조인하면 새는 데가 있다.** 공정위는 「에쓰-오일주식회사」·「씨제이이엔엠(주)」로
쓰고 DART 는 「에쓰오일」·「CJ ENM」으로 쓴다. 법인등록번호는 13자리 숫자라 그런 문제가
없다 — 공정위와 DART(`company.json` 의 `jurir_no`) 양쪽에 하이픈 없는 같은 형식으로 있다.

37 개사로 대조했다.

| | 건수 |
|---|---|
| 번호 조인 ✔ · 이름 조인 ✔ | 22 |
| **번호 조인 ✔ · 이름 조인 ✘** | **3** — 에쓰오일 · CJ ENM · 에스엠 |
| 번호 조인 ✘ · 이름 조인 ✔ | **0** |
| 둘 다 ✘ (공정위에 없는 비집단) | 12 |

**역방향 손실이 없다.** 번호 조인이 이름 조인을 완전히 포함하고 3 건을 더 잡는다.

우선순위는 **공정위가 기본, 지주코드일 때만 DART** 다. 공정위가 `K6499`·`M7151` 로
분류했는데 DART 가 사업 코드를 주면 DART 를 쓴다 — 지주회사 체제라 개별 신고가 실질을
가리는 경우다. 앞서 계열사 조인에서 성격을 잃었던 둘이 이걸로 풀린다.

```
SK이노베이션   공정위 K6499  →  DART C192  (석유정제)
SKC          공정위 K6499  →  DART C204  (플라스틱 제품)
SK스퀘어       공정위 K6499  →  그대로     (양쪽 다 지주코드 · 실제로 투자지주다)
```

#### 공동 소유 법인은 어디로 귀속시키나

법인등록번호가 **18 건 중복**한다. 롯데지에스화학·롯데에스케이에너루트·지에너지(에스케이
+지에스)·에이치디씨신라면세점처럼 **이름에 양쪽이 들어간 합작사**가 대부분이다.
공정위가 두 집단 모두에 신고하는 것이고, **지분법상 양쪽 반영은 틀린 게 아니다.**

다행히 **사업형태 판정은 어느 집단으로 보나 같다 — 18 건 전부 동일하다.** 같은 법인이니
KSIC 도 같아서다. 그래서 **분류에는 영향이 없고, 남는 문제는 목록 중복 하나**다.
업무키트 대상 목록에 같은 회사가 두 번 나오면 안 되므로 `fetch_ftc.dedupe()` 로
법인등록번호 기준 유일화한다(3,539 → 3,521). 집단 소속은 버리지 않고 `기업집단명들` 에
모아 남긴다 — 그룹 단위로 볼 때 쓴다.

**지배 집단을 가려야 할 때의 기준은 K-IFRS 1110 호 지배력이다.** 지분율 숫자보다 이게
객관적이고 공개 자료로 확인된다 — **그 법인을 종속기업으로 연결하는 집단이 지배자**다.
DART 사업보고서 주석의 종속기업 목록을 보면 된다. 어느 쪽도 연결하지 않으면(공동기업)
가르지 않고 중복을 유지한다.

`controlling_group()` 이 이 규칙을 돌린다. 후보 집단마다 지배 후보 회사들의 주석을
받아 종속기업 목록에 대상 이름이 있는지 본다. **18 건 전체에 돌린 결과다.**

| 상태 | 건수 | 예 |
|---|---|---|
| **지배 집단 확정** | 7 | 애경산업·모두락애경산업·에이제이피·에이텍세종·원씽 → **애경**(에이케이홀딩스의 종속기업) · 씨텍 → **엘지** · 롯데지에스화학 → **롯데**(롯데케미칼의 종속기업) |
| **공동기업 확정** | 10 | 롯데에스케이에너루트 · 지에너지 · 에이치디씨신라면세점 · 서울복합물류 2 건 · 울산에너루트2호 · 코드 · 가승개발 · 스타필드수원 · 오리온농협 — 양쪽을 다 읽었고 어느 쪽도 연결하지 않는다 |
| **확인 실패** | 1 | 아이앤케이신항만 — 고려에이치씨 집단에 **사업보고서를 내는 회사가 없다**(비상장 집단) |

후보 수(`limit`)를 4 에서 8 로 늘려 확인 실패를 4 건에서 1 건으로 줄였다. 남은 1 건은
후보를 더 늘려도 안 된다 — 그 집단 자체가 보고서를 내지 않는다.

**「확인했으나 없었다」와 「확인 자체가 못 했다」를 반드시 갈라야 한다.** 처음엔 둘을
「공동기업」으로 뭉쳤는데, 그러면 자료가 없어서 못 가른 것을 공동기업이라 잘못 읽는다.
그래서 근거에 확인한 곳 수를 남긴다 — `(확인 지에스:2곳 · 카카오:0곳)` 처럼 한쪽이
0 곳이면 공동기업이라 단정하지 않는다.

못 읽는 이유는 그 집단에 **사업보고서를 내는 회사가 지배 후보 안에 없어서**다.
카카오 집단의 후보는 카카오벤처스·케이큐브홀딩스 같은 비상장 지주라 보고서가 없다.
후보 수(`limit`)를 늘리면 줄지만 집단마다 수 MB 씩 받아야 하니 값이 비싸다.

한 건은 손으로도 대조해 규칙이 맞는지 확인했다.

```
AK홀딩스 주석  →  종속기업 목록에 애경산업이 있다          → 애경 귀속
태광산업 주석  →  애경산업 언급이 0 곳이다(연결하지 않음)
```

구현에서 걸린 데는 **이름 표기**였다. 종속기업 목록은 「애경산업㈜」로 쓰고 공정위는
「애경산업(주)」로 쓴다 — `㈜` 를 떼지 않아 처음엔 하나도 안 맞았다. 지주회사를 찾는
쪽도 마찬가지다. 공정위 「에이케이홀딩스(주)」와 DART 「AK홀딩스」를 잇지 못해 후보에서
빠졌다. 법인 형태 표기(`㈜`·`(유)`·`주식회사`…)를 떼고 한글 알파벳 표기(에이케이 → AK,
에이치디씨 → HDC …)를 영문으로 모으도록 고쳤다. **긴 표기부터 바꿔야 한다** —
「에이치디씨」가 「에이치디」에 먼저 걸리면 `HD씨` 가 된다.

**버그 둘을 잡았다. 둘 다 조용히 틀린 답을 냈다.**

첫째, **동명 법인**이다. `corpCode.xml` 에 「카카오」가 둘 있는데 종목코드 없는 2017 년
법인이 먼저 나온다. 그걸 잡으면 사업보고서가 없어 판정이 통째로 실패한다 — 확인 실패
4 건 중 3 건이 이것 때문이었다. **상장사를 먼저, 그 다음 수정일 최근 순으로** 색인한다.

```
00918444  종목 없음    수정 20170630   ← 처음엔 이걸 잡았다
00258801  종목 035720  수정 20240329   ← 실제 카카오
```

둘째, **순환**이다. 후보를 8 개로 늘리니 태광 후보에 「애경산업(주)」이 들어갔고,
애경산업의 종속기업 목록에 모두락애경산업·에이제이피가 있어서 「태광이 지배한다」는
결론이 났다. 하지만 애경산업 자체가 애경 소속이다(위 표의 확정 결과). **귀속이 미정인
중복 법인을 지배 근거로 쓰면 순환**이므로 후보에서 뺀다. 공정위 소속 목록은 지분만
있어도 넣기 때문에 남의 집단 회사가 섞인다는 걸 여기서 알았다.

지배 후보를 뽑는 데도 함정이 있었다. **지주회사만 보면 놓친다** — 묶음노드로 잡히는
K6499 에는 PEF·벤처투자사가 섞인다(태광의 「티투프라이빗에쿼티」, 카카오의
「카카오벤처스」). 반대로 집단명이 든 회사만 보면 애경에서 실패한다 — 애경케미칼
·애경산업이 자리를 다 차지하고 정작 지배자인 에이케이홀딩스는 이름에 「애경」이 없고
매출도 작아 밀린다. 그래서 **지주회사는 무조건 첫 후보로 넣고**, 그 뒤에 집단명 포함
·매출 상위를 점수로 세운다.

지분율 기준(공정거래법 시행령의 「30% 이상 + 최다출자자」)도 있지만 공정위 소속회사
자료에는 지분율이 없다. 주식소유현황은 별도 자료라 한 번 더 받아야 하고, 연결 여부는
이미 우리가 읽는 주석에 있으므로 그쪽이 싸다.

세그먼트 쪽 계열사 조인은 여전히 이름으로 한다. 부문 표에는 이름만 실리고 법인등록번호가
없기 때문이다 — 그래서 「에스케이씨」와 「SKC」를 맞추는 일이 남는다.

#### DART 업종코드는 되돌릴 수 있다

전에는 「대분류 문자가 없고 자릿수도 제각각이니 판정에 쓰지 말라」고 적어 두었다.
다시 보니 **되돌릴 수 있다.** KSIC 대분류 문자는 앞 2자리 숫자로 완전히 결정된다
(10~34 = C, 45~47 = G, 58~63 = J …). DART 는 그 문자만 빼고 숫자는 그대로 준다.

```
264   → C264      471   → G471      58211 → J58211
20111 → C20111    70113 → M70113    29280 → C29280
```

공정위 KSIC 와 겹치는 22 개사로 대조했다. **중분류는 20 건이 맞았고 2 건이 어긋났다.**
어긋난 2 건 중 SK이노베이션은 **DART 가 더 정확했다** — `C192`(석유정제)가
공정위 `K6499`(지주회사)보다 사업 실질에 가깝다. 나머지 1 건(에코프로)은 DART
`K64992` 대 공정위 `M7151` 로 표기만 다르고 둘 다 지주라 판정 결과가 같다.

**완전일치가 0 건인 건 자릿수 때문이다.** 삼성전자는 DART 가 3자리(`264`), 공정위가
4자리(`C2642`) 다. 회사가 신고한 수준을 그대로 실으므로 세분류까지 믿으면 안 된다 —
**B 축 2단은 이 값만으로 단정하지 않는다.**

값이 큰 곳은 여기다. 위 37 개사 중 **15 개가 공정위에 없다**(에쓰오일·KB금융
·신한지주·알테오젠·HLB·리노공업·동진쎄미켐·펄어비스·에스엠·클래시스 등).
비집단 상장사에게는 DART 가 유일한 KSIC 출처다.

#### 금융지주는 법인으로 보면 「지주·투자」다

DART 로 확인했다. 공정위에 없는 금융지주가 전부 `K64992` 로 신고한다.

```
KB금융 · 신한지주 · 하나금융지주 · 우리금융지주 · 한국금융지주 · 메리츠금융지주
   → K64992 → 지주·투자 / 다품목·범용
기업은행    → K64121 → 금융 / 은행업            ← 은행 본체라 바로 잡힌다
삼성카드·생명·화재 → 공정위에 있다(삼성 집단) → 여신전문 / 보험
```

금융지주가 공정위에 없는 건 대기업집단 지정에서 **금융전업집단이 빠지기** 때문이다.

**목적으로 되짚으면 이게 문제다.** 은행 업무키트의 대상을 추리는데 KB금융이
「지주·투자」로 분류되면 대상에서 빠진다. 실제 은행 업무는 KB국민은행이 한다.

**여기서 세그먼트 분할이 값을 한다.** KB금융의 부문 표를 나누면 은행·증권·손해보험
·신용카드·생명보험이 나오고, 그 「은행부문」이 은행 키트의 대상이다. 법인 단위로는
지주회사가 맞고 대상은 그 아래 사업이라는 것 — 인스턴스를 실질 단위로 세우는 이유가
바로 이것이다.

### 세그먼트 수집 — 주석을 읽는다

**DART Open API 에 세그먼트 전용 API 가 없다.** 재무정보 그룹 7개 API 는 회사 단위
계정만 준다. 그래서 사업보고서를 직접 파싱한다. 인증키는 `DART_API_KEY` 환경변수
또는 `engine/.env` 에 둔다(`.gitignore` 에 걸려 커밋되지 않는다).

**본문이 아니라 주석을 읽는다.** 본문의 부문 표는 서식이 회사마다 달라 커버리지가
26% 였다. 본문에도 「부문별 정보」 섹션이 있지만 그건 XBRL 뷰어용이라 부문명이 열
헤더가 아니라 축 레이블(「기업 전체 총계」)로 들어가 못 쓴다. 반면 **재무제표 주석**의
영업부문 공시는 K-IFRS 서식을 따라 훨씬 표준적이다.

```bash
python fetch_dart.py 051910        # 종목코드 또는 고유번호
```

공시 ZIP 안에서 주석 파일을 내용으로 골라낸다 — 파일명 접미사(`_00760`)는 회사마다
번호가 다르므로, **본문만 접미사가 없다**는 규칙으로 본문을 뺀 뒤 남은 후보를 파싱해
부문이 나오는 파일을 쓴다. 연결·별도가 함께 오면 연결이 정본이다.

#### 서식 차이를 흡수한 곳

| 함정 | 대응 |
|---|---|
| 헤더가 2단이고 「구 분」이 rowspan → 헤더가 데이터보다 한 칸 짧다 | 앞이 아니라 **뒤에서부터** 맞춘다 |
| 부문마다 당기·전기 **두 칸**을 쓴다(에쓰오일) | stride 1·2 를 시도하고 **합계 = 나머지 합**인 쪽을 택한다 |
| 수익 행이 한 표에 넷이다(SK이노베이션의 총·내부·순·기타영업) | 「외부고객 > 순매출 > 총매출」 우선순위, 내부거래 행 제외 |
| 값이 없는 라벨 행(LG생활건강 「매출액:」) | 값이 하나도 없는 행은 후보에서 뺀다 |
| 부문이 **행**에 있는 세로형(LS·LS일렉트릭) | 부문명 = 숫자가 아닌 마지막 칸, 매출 = 그 다음 칸 |
| 단위가 회사마다 다르다(CJ제일제당은 천원) | 표 **바로 앞** 캡션을 읽어 백만원으로 통일한다 |
| 지역별 정보 표가 부문 표보다 열이 많다 | 지역명은 완전일치로 막는다 — 「해외」는 빼고 「해외사업」은 살린다 |
| 종속기업 목록이 제품 표로 보인다(SK하이닉스 18곳) | 「지분율·소재지」 열이 있으면 뺀다. 매출 없는 부문은 인정하지 않는다 |
| 「하나의 보고부문」인데 아래에 지역 표가 있다(기아) | 단일 보고부문 문구를 인식해 **0 건이 정답**으로 둔다. 문서 단위로 본다 — 섹션별로 보면 그 문구가 없는 섹션에서 엉뚱한 표를 읽는다 |
