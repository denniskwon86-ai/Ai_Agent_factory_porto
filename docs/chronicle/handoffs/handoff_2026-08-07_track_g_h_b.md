### 이 게이트가 잡은 것

1. **`GET /api/v1/factory/formats` 가 익명에게 200** — 응답의 `prompt_injection` 은 **모든
   에이전트 프롬프트에 그대로 들어간다.** 쓰기 3개도 무방비여서 익명이 문장을 심을 수 있었다.

2. **`crosswalk` 는 읽기만, `workspace` 는 쓰기만 막혀 있었다** — 정확히 반대 모양이고,
   **한쪽만 훑는 점검은 두 파일 모두에 초록을 준다.**
3. **FastAPI 는 본문 검증을 인가보다 먼저 한다.** 빈 본문 POST 의 422 를 「막혔다」로 세면

### 게이트의 세는 규칙 (건드리지 말 것)

- **422·404·409 를 통제로 세지 않는다** — 값을 채우면 열린다
- **200 은 «0건 + `blocked_reason`» 일 때만 인정한다** — 면제 목록을 만들지 않고 그때그때 확인
