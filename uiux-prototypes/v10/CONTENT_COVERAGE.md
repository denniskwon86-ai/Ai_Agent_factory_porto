# V10 콘텐츠 적용표

V10은 Atlas 상담을 제품의 진입점으로 삼되, 단순 대화가 아니라 실제 실행계획과 제품 기능으로 연결한다.

- C01·C12: 상단 회사·조직·권한 범위, 회사 전환과 CI 설정
- C02: Task ID 없이 회사 전체 상태와 사용자의 목표를 이해하는 Atlas 상담
- C03: 첫 사용자 상담, 선택형 명확화, 추천 데이터셋과 다음 행동
- C04·C09: 상담 결과를 RFP·기획·아키텍처·WBS·에이전트 워크플로우로 변환
- C05·C06·C11: 사업계획·경영 시뮬레이션, 운영 그리드, 전사 포트폴리오로 연결
- C07·C08: 데이터 준비도, MDM·카탈로그·지식 허브, ERP/MES/MCP·Crosswalk, 계보·계약·감사
- C10: HOTL·품질·자가복구·실패 인계·모델 비용 계측과 릴리스 라이브러리

대화 속 데이터 수치는 화면 구성 검토를 위한 예시이며 실제 회사 데이터가 아니다.
