# AI Factory Studio UI/UX Prototype V2

## 목적

기존 A~D 및 기능별 시안에서 화면마다 달랐던 색상·네비게이션·카드·상태 표기를 하나의 제품 언어로 통일한 검토용 HTML 시안이다. 실제 프론트엔드 코드를 교체하지 않으며, 기능과 화면의 우선순위를 합의하기 위한 프로토타입이다.

## 공통 디자인 언어

- **네이비 사이드바**: 회사·사업부·프로젝트라는 업무 범위를 항상 인지시킨다.
- **밝은 작업 캔버스**: 데이터, 문서, 경영 수치를 오래 읽는 사용자를 위한 기본 작업면이다.
- **블루 CTA / 틸 상태색**: 실행과 정상 상태를 명확히 구분한다. 경고·차단은 앰버·레드만 사용한다.
- **근거와 다음 행동**: Atlas 권고, 생성 작업, 디지털 트윈 결과는 출처·승인·범위 또는 다음 행동을 함께 표시한다.

## 시안 목록

| 파일 | 화면 목적 |
|---|---|
| `index.html` | V2 전체 방향과 화면 선택 |
| `atlas-home.html` | 최초 사용자·전역 AI 비서·추천 작업 |
| `factory-workspace.html` | 요구사항부터 기획/구현/검증까지의 SW 생성 통제실 |
| `digital-twin.html` | 가정·결과·영향 경로를 보여 주는 경영 시뮬레이션 |
| `knowledge-hub.html` | 지식 팩·MDM·승인·조직 범위 관리 |
| `enterprise-portfolio.html` | 사업부와 전사를 잇는 경영진 포트폴리오 |
| `organization-brand-settings.html` | 회사 CI·대표색·조직별 적용 규칙을 관리하는 환경설정 |

## 확인 방법

`index.html`을 브라우저로 열거나, 프로젝트 루트에서 아래 명령으로 정적 서버를 실행한 뒤 접속한다.

```powershell
python -m http.server 8090 --directory uiux-prototypes/v2
```

브라우저 주소: `http://localhost:8090`
