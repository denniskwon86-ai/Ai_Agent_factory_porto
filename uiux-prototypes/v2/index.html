AI Factory Studio · unified interface direction

복잡한 엔터프라이즈 작업을
“지금 무엇을 하면 되는가”로 정리합니다.

V2는 기존 시안의 기능 폭을 유지하면서도, 공통 내비게이션·조직 컨텍스트·상태 태그·카드·CTA 문법을 하나로 통일했습니다. 밝은 작업 캔버스는 수치와 문서를 읽기 쉽게 만들고, 네이비 사이드바는 어느 화면에서도 사용자의 업무 범위를 고정해 줍니다.

01 · 항상 보이는 업무 범위

회사·사업부·프로젝트 컨텍스트를 상단과 좌측에서 일관되게 확인합니다.

02 · 정보보다 다음 행동

모든 화면의 핵심 카드는 “무엇을 알았는가”와 “지금 무엇을 할까”를 함께 보여 줍니다.

03 · AI는 근거를 남긴다

Atlas 권고·지식·시뮬레이션은 데이터 출처, 신뢰도, 승인 상태를 숨기지 않습니다.

01Atlas Home

처음 온 사용자를 상담·추천·준비작업으로 연결하는 전역 AI 비서 홈.

02Factory Workspace

요구사항부터 기획·구현·검증까지 한 실행 흐름으로 보여 주는 생성 통제실.

03Digital Twin

외부지표·운영 가정이 손익과 운영지표에 미치는 영향을 비교하는 시나리오 화면.

04Knowledge Hub

지식 팩·MDM·외부지표를 승인·범위·근거 중심으로 관리하는 데이터 허브.

05Enterprise Portfolio

조직별 프로젝트·시뮬레이션·데이터 준비도를 경영 관점에서 묶는 포트폴리오 화면.

06공통 컴포넌트

컨텍스트 스위처, 상태 태그, 근거 카드, 다음 행동, Atlas 도움말을 전 화면에 재사용합니다.
