# Revision V2-1 · Direction Validation

Revision V3의 양산형 관리자 화면 문제를 폐기하고 Revision V2의 독창성을 제품화하기 위한 대표 화면 3종이다.

1. `enterprise/`: 회사·제품 진입 세계관
2. `factory/`: 현업 SW Factory 생산라인
3. `twin/`: 경영 Digital Twin 시나리오룸

공통 원칙:

- UI·본문 글꼴은 Pretendard/Noto Sans KR로 통일한다.
- 수치·코드만 고정폭 글꼴을 사용한다.
- 카드 대시보드와 동일한 공통 상단 바를 반복하지 않는다.
- 각 화면의 공간과 상호작용이 기능 자체를 설명해야 한다.
- 예시 데이터, 회사 범위, 근거 시점, 권한 안전성을 명시한다.
