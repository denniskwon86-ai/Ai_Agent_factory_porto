## 시각 기준선 — 2026-08-04 Supervisor 재확인

- **제품 기본 업무 표면은 라이트 테마다.** 밝은 회색 페이지, 흰 카드, 진한 잉크 텍스트를 기본으로 한다.
- LS Navy는 전체 화면을 어둡게 칠하는 다크 테마가 아니라 **상단 구조 바·좌측 역할 레일·전역 AI 레일**에 사용한다.
- LS Red는 위험·최종 확정 등 제한된 핵심 행동에만 쓴다. 일반 생성·이동 버튼을 Red로 만들지 않는다.
- 코드 편집기·서버 로그·렌더링 샌드박스처럼 장시간 판독에 필요한 영역만 목적이 명확한 다크 표면을 허용한다.
- 신규 화면만 밝고 런처·통제실은 다크인 혼합 상태를 최종 디자인으로 인정하지 않는다.
- Tailwind 숫자 스케일을 전역 반전하지 않는다. 제품 공통 셸과 의미 토큰으로 범위를 명시하고 시각 게이트를 거친다.

## 구현 원칙

- 기존 `ControlPanel`, `TimelinePanel`, `PreviewPanel` 기능을 폐기하지 않고 선택한 업무·프로젝트의 상세 작업 공간으로 연결한다.
- 메인 화면 전환 전에 기존 화면과 병행 가능한 Read-only 카나리로 이식한다.
- 화면에 표시하는 수치·상태·추천은 실제 API 근거가 있을 때만 노출한다.
- Atlas의 읽기 답변과 실행 명령을 분리하며 실행은 HOTL 승인을 거친다.
- 회사 Context·권한은 모든 집계·검색·대화·실행에서 Fail-closed로 적용한다.
