# Set B 기능 적용표

두 번째 세트는 공통 회사 Shell·글꼴·상태색을 공유하고, 기능별 작업 구조만 다르게 설계한다.

| 버전 | 화면 역할 | 기능 특성에 맞춘 구조 | Set A 비교 대상 |
|---|---|---|---|
| V1 | 전사·프로젝트 홈 | 영향도 중심 Mission Queue와 신뢰 상태 | 3패널 Product Control Room |
| V2 | 제품 작업 공간 | 공간·파일·탭·명령 검색 | Desktop OS의 창·Dock |
| V3 | HOTL 결정 | 동일 평가 기준의 Evidence Matrix | 시네마틱 Decision Theater |
| V4 | 공장 운영 | 설비 상태와 이벤트·작업지시 Timeline | P&ID Plant Mimic |
| V5 | 경영계획 | 부서 반복 입력·취합·검증 Workbook | 문서·주석 Planning Binder |
| V6 | 회사 마스터·사이트맵 | 그룹→회사→사업부→공장 Tree와 Capability | Spatial Constellation |
| V7 | 프로젝트 실행 | WBS 의존성·Critical Path·Blocker | 주체별 Process River |
| V8 | 개인화 | 일정·승인·집중시간 Day Planner | Editorial Personal Portal |
| V9 | 가치사슬·경영 | 성과 원장과 손익 원인 Trace | Value Flow Sankey |
| V10 | 최초 상담 | 선택형 6단계 Guided Setup | Atlas Co-Creation Canvas |

공통으로 회사·조직·권한, Atlas, SW 생성, Digital Twin, 운영, 지식·MDM·카탈로그, MCP·Crosswalk, Agent, 품질·자가복구·비용, 릴리스·전사 포트폴리오로 이동할 수 있다.
