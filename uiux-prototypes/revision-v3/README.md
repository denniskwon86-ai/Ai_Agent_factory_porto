# Revision V3 · Unified Product Set

Revision V2가 화면별 개성과 실험을 극대화한 세트라면 Revision V3는 실제 하나의 제품군으로 보이는 통일성과 기능별 작업 적합성을 함께 검증하는 세트다.

- UI·본문 글꼴: Pretendard → Noto Sans KR → Segoe UI 순서
- 고정폭 글꼴: 숫자·코드·설비값에만 사용
- 회사 Shell·상태색·버튼·간격은 공통 `set-b.css` 사용
- 화면 구조는 기능 특성에 따라 서로 다르게 구성

브라우저 주소: `http://localhost:8090/revision-v3/`
