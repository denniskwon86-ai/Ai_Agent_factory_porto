# AI Factory Studio UI/UX Revision V2

`DESIGN_DIVERGENCE_REVISION_PLAN.md`의 비판 기준을 실제 화면으로 반영한 독립 수정본이다.

- 기존 `v1/`~`v10/`은 비교를 위해 보존한다.
- 수정본은 `revision-v2/v1/`~`revision-v2/v10/`에 위치한다.
- 모든 화면은 본문 14px 이상을 기본으로 하고 작은 보조문구 남용을 피한다.
- 동일한 C01~C12 제품 기능을 서로 다른 공간 모델로 표현한다.
- 정적인 이미지가 아니라 최소 한 개 이상의 의미 있는 상호작용을 제공한다.

```powershell
python -m http.server 8090 --directory uiux-prototypes
```

브라우저 주소: `http://localhost:8090/revision-v2/`
