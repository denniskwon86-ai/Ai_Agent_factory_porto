# Revision V2 콘텐츠·용도 적용표

Revision V2는 모든 기능을 모든 화면에 억지로 나열하지 않는다. V6가 전체 기능 사이트맵을 담당하고 각 전문 화면은 사용 문맥에 필요한 기능을 전면에 배치한다. 공통 회사 Shell에서 회사·권한·Atlas·전체 기능으로 이동할 수 있다는 전제로 설계한다.

| 버전 | 대표 용도 | 전면에 배치한 핵심 기능 | 공통 Shell에서 접근하는 기능 |
|---|---|---|---|
| V1 | 현재 제품 통제실 기준선 | 프로젝트, SW 생성, HOTL, 품질·자가복구, 미리보기 | 회사 지도, 지식·MDM, Twin, MCP, 포트폴리오 |
| V2 | 회사 업무 Desktop OS | Dock, 다중 업무 창, 개인 Action Center, Atlas Command | 모든 기능 앱을 Dock·Command Palette로 실행 |
| V3 | 중요 HOTL 의사결정 | 선택지, 영향, 근거, 비용, 승인 | Product Map에서 SW·Twin·데이터·릴리스 접근 |
| V4 | 공장 운영 통제 | 설비·공정·품질·물류, 경보, 현장 SW, Twin | 릴리스·전사 포트폴리오는 상위 운영 Shell에서 접근 |
| V5 | 경영계획 작성·검토 | 계획 문서, 외부지표, 근거, 주석, 승인, Twin 결과 | SW 생성·에이전트·릴리스는 문서 실행과제에서 연결 |
| V6 | 전체 기능 사이트맵 | 회사·Atlas·SW·에이전트·릴리스·Twin·운영·데이터·포트폴리오 | 해당 없음 — 전사 탐색 허브 |
| V7 | 프로젝트 하위 진행 모듈 | 현업·AI·데이터·경영 레인, 병목, 담당, 비용, HOTL | 하단 제품 Dock으로 전체 기능 접근 |
| V8 | 개인화 업무 포털 | 개인 결정, Atlas 브리핑, 프로젝트, Twin, 데이터 신뢰 | 개인 업무공간에서 전체 기능 접근 |
| V9 | 전사 가치사슬·경영 | 수주·구매·계획·생산·재고·손익 Sankey, 시나리오 | 하단 가치사슬 Dock에서 SW·에이전트·데이터·릴리스 접근 |
| V10 | 최초 상담·신규 업무 공동설계 | Atlas 상담, 데이터 준비도, 에이전트, SW·Twin Blueprint | 하단 전체 제품 Dock으로 모든 기능 접근 |

## 공통 안전·신뢰 규칙

- 최상위 컨텍스트는 회사·사업부·공장 계층과 사용자 권한이다.
- 다른 조직 데이터는 Fail-closed와 존재 은폐 원칙을 따른다.
- Atlas는 Task ID 없이 회사 전체 상태를 질의할 수 있다.
- 예시 데이터는 실제 회사 수치로 오해되지 않게 표시한다.
- MDM·카탈로그·용어·계보·품질·계약·Crosswalk·감사가 AI 산출물의 근거가 된다.
- LLM 품질·비용·컨텍스트·자가복구·실패 후 인계 상태를 사용자에게 노출한다.
