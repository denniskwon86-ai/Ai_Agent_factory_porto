# V1~V10 UI/UX 선택·통합 가이드

> 2026-07-30 최신 판단: `revision-v3/` Set B는 글꼴 통일 외에는 양산형 관리자 화면으로 판단되어 최종 시각 후보에서 제외했다. 현재는 `revision-v2/`의 독창성을 유지하면서 UI·본문 글꼴과 접근성 규칙만 통일한 `revision-v2-1/` 대표 화면 3종을 먼저 검증한다. 기존 화면은 탐색 이력으로 보존한다.

## 1. 선택 원칙

최종 제품은 하나의 시안을 통째로 채택하지 않는다. 사용자 여정별로 가장 적합한 정보구조와 상호작용을 선택하고, 회사 CI·색상·타이포그래피·버튼·상태 표현은 하나의 공통 디자인 시스템으로 통합한다.

필수 제품 콘텐츠는 `CONTENT_BASELINE.md`의 C01~C12이며, 디자인 선택 때문에 기능이 누락되거나 새로운 기능처럼 오해되는 예시를 임의로 추가하지 않는다.

## 4. 통합 시 반드시 지킬 UX 규칙

1. 핵심 본문은 14px 이상, 보조 정보도 11px 미만으로 남용하지 않는다.
2. 사용자가 지금 눌러야 하는 주 행동은 화면 중심 또는 작업 문맥 바로 옆에 1개만 강조한다.
3. Atlas는 Task ID 없이 회사 전체를 질의할 수 있어야 하고, 답변 근거·시점·권한 범위를 표시한다.
4. 예시 수치는 반드시 예시임을 표시하고 실제 데이터처럼 오해시키지 않는다.
5. 권한은 Fail-closed이며 다른 조직 자원의 존재 여부도 노출하지 않는다.
6. 회사 CI와 상징색은 적용하되, 오류·경고·성공·승인 상태색과 접근성 대비는 제품 공통 토큰으로 보호한다.
7. V7의 레인은 프로젝트 내부 모듈로 사용하고 전역 내비게이션을 대체하지 않는다.
8. V8 개인화는 추천 이유와 전체 기능 사이트맵으로 돌아가는 통로를 제공한다.
