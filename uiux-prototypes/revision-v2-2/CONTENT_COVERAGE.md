# Revision V2-2 기능 콘텐츠 보존표

시각적 개성을 만들기 위해 제품 기능을 누락하거나 임의 기능으로 바꾸지 않았는지 확인하는 표다. 세 화면은 전체 제품을 모두 복제하는 화면이 아니라, 각자의 주 기능과 다른 기능으로 이어지는 연결점을 표현한다.

| 제품 기능 | Enterprise World | Software Production Line | Future Scenario Room |
|---|---|---|---|
| 회사·사업부·공장·가상회사 | 중심 회사 계층과 회사 전환 | 생산 주문의 회사·부서 범위 | 시뮬레이션 회사·기간 범위 |
| CI·상징색·산업 프로필 | 회사 코어와 환경설정 진입 | 회사 브랜드를 생산 주문에 상속 | 회사 컨텍스트와 결과에 상속 |
| 권한·조직 격리 | Fail-closed 및 타 범위 은폐 | 생성·릴리스 범위 고정 | 데이터·시나리오 공유 범위 고정 |
| Atlas 전역 비서 | 전체 시스템 상담·제어 | Task ID 없는 라인 브리핑·개입 | 결과 해석·대안 추천 |
| 현업 SW 생성기 | SW Factory 진입점 | 요구부터 릴리스까지 핵심 생산라인 | Twin과 결합된 업무 SW로 연결 |
| 선택형 요구 명확화 | Atlas 진입점 | CLARIFY 공정 | 시나리오 목표·가정 설정에 적용 가능 |
| Agent·워크플로우 | Agent Mesh 지도 | 역할·모델·HOTL 조립 및 실행 | 시뮬레이션·분석 Agent 근거 |
| HOTL·품질·자가복구 | 제품 상태로 연결 | PROVE, 최대 3회 복구와 종료·인계 | 중요 시나리오 승인·공유로 확장 |
| MDM·카탈로그·용어·Graph RAG | Knowledge·MDM 코어 | GROUND 입력 근거 | 결과 계보·신뢰도 근거 |
| MCP·업무 시스템·파일 | 데이터 코어와 Operations 연결 | 실제 데이터 투입·Crosswalk | ERP/MES 및 외부지표 스냅샷 |
| 전사 운영·부서 협업 | Operations 기능 지도 | 생성 제품의 조직 배포 | 업무 변화의 전사 영향 |
| Digital Twin·경영 시뮬레이션 | 전사 기능 진입점 | 생성 제품 유형으로 명시 | 조건 조정·미래 궤적·의사결정 |
| 외부환경·검증 지표 | 데이터 허브에서 연결 | 승인 데이터 팩 투입 | 공공 확정치·시점·스냅샷 표시 |

## 남은 상세화 대상

- 대규모 회사 계층 탐색과 즐겨찾기
- 실제 HOTL 비교·승인 화면
- 3회 자가복구 실패 후 원인 묶음·재시도·중단·전문가 인계
- 데이터 계약·품질·계보 상세 드릴다운
- 복수 시나리오 겹쳐보기와 승인 버전 관리
- 접근성, 키보드 탐색, 반응형 및 고밀도 모드
