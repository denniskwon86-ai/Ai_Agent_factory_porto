# Revision V2-2 · LS Brand Edition

Revision V2-1의 대표 화면 3종을 유지하면서 LS 공식 CI 컬러 시스템을 제품 경험에 적용한 비교 시안이다.

1. `enterprise/`: LS Blue 기반 회사·제품 진입 세계관
2. `factory/`: Blue 구조와 Red 활성 공정을 사용하는 SW 생산라인
3. `twin/`: Red 시나리오와 Green 성과를 구분하는 경영 Digital Twin

## 적용 원칙

- LS Blue `RGB(10, 30, 90)`는 회사 구조, 신뢰 기반, 내비게이션에 사용한다.
- LS Red `RGB(250, 0, 45)`는 현재 선택, 핵심 행동, 미래를 향한 전진에 사용한다.
- Green `RGB(0, 155, 180)`은 완료·긍정 성과·검증된 연결에 사용한다.
- Light Blue `RGB(5, 105, 160)`는 정보 연결과 보조 강조에 사용한다.
- Gray `RGB(125, 130, 130)`는 중립 정보와 비활성 상태에 사용한다.
- 경고·위험은 브랜드 Red와 의미가 충돌하지 않도록 별도 오렌지 계열을 함께 사용한다.
- 화면 구조와 기능 콘텐츠는 V2-1과 동일하게 유지하여 색상 체계의 효과를 독립 비교한다.

공식 근거와 상용화 시 주의사항은 `BRAND_APPLICATION_GUIDE.md`를 참고한다.
