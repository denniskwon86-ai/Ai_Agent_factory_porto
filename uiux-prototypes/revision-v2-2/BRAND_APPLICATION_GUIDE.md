# LS CI 기반 제품 테마 적용 가이드

## 1. 공식 근거

- 참고 페이지: <https://www.lsholdings.com/ko/media/ci>
- 확인일: 2026-07-30
- LS Blue: PANTONE 281C, `RGB(10, 30, 90)`, `#0A1E5A`
- LS Red: PANTONE 199C, `RGB(250, 0, 45)`, `#FA002D`
- Green: PANTONE 312C, `RGB(0, 155, 180)`, `#009BB4`
- Blue: PANTONE 3005C, `RGB(5, 105, 160)`, `#0569A0`
- Gray: PANTONE 430C, `RGB(125, 130, 130)`, `#7D8282`

공식 설명에 따르면 Blue는 투명성과 건실함, Red는 도전적이고 진취적인 사고를 의미한다. 화살표 형태는 미래를 향한 전진과 무한 성장을, 곡선은 고객을 향한 마음을 상징한다.

## 2. 제품 의미 체계

| 컬러 | 제품에서의 역할 | 적용 예시 |
|---|---|---|
| LS Blue | 회사·권한·신뢰·구조 | 기업 배경, 상단 바, 데이터 기반, 제품 프레임 |
| LS Red | 현재 선택·핵심 실행·미래 전진 | 주요 CTA, 활성 공정, 선택 시나리오, 핵심 노드 |
| Green | 완료·긍정·연결 정상 | 완료 공정, 납기·품질 개선, 연결 상태 |
| Light Blue | 데이터 흐름·보조 정보 | 관계선, 보조 라벨, 탐색 강조 |
| Gray | 중립·대기·비활성 | 보류 공정, 설명 정보, 경계선 |
| 별도 Orange | 경고·위험 | 비용 상승, 위험 KPI, 주의 상태 |

LS Red를 오류색으로만 쓰면 브랜드의 진취적 의미가 훼손되므로, 제품 전반에서는 핵심 행동과 활성 상태에 우선 사용한다. 위험은 문맥·아이콘·오렌지 계열을 함께 사용해 구분한다.

## 3. 화면별 적용

### Enterprise World

- 회사 세계 전체를 LS Blue로 구성한다.
- 중심 회사 또는 현재 선택 노드만 LS Red 링으로 강조한다.
- 데이터·지식 연결선은 Green, 일반 기능 관계는 Light Blue로 구분한다.
- CI 마크와 조직 범위가 최상단에서 항상 확인되도록 한다.

### Software Production Line

- 설비·프레임은 Blue, 현재 생산 공정은 Red, 완료 공정은 Green으로 분리한다.
- 제품 카드와 주요 버튼만 Red를 사용하여 사용자의 다음 행동을 중앙에 둔다.
- 품질·비용·복구 정보는 색상만이 아니라 숫자와 문장으로 함께 전달한다.

### Future Scenario Room

- 기준안은 Light Blue, 사용자가 조정 중인 시나리오는 Red 궤적으로 표현한다.
- 긍정 성과는 Green, 위험 결과는 Orange로 표시한다.
- 조건 조정·시나리오 저장 같은 핵심 행동에 Red를 사용한다.

## 4. 상용화 전 필수 확인

1. 현재 시안의 `LS` 문자는 테마 검토용 표현이며 공식 로고 원본을 재현한 것이 아니다.
2. 실제 제품 적용 전 LS 및 해당 계열사 CI 담당 부서의 로고 사용 승인을 받아야 한다.
3. 승인된 SVG/PNG 원본, 최소 보호 공간, 최소 크기, 배경별 Positive/Negative 규정을 디자인 시스템에 등록한다.
4. 계열사별 대표 CI와 상징색이 다를 경우 회사 마스터에서 테마 토큰을 상속·재정의하도록 구현한다.
5. 색각 이상 사용자를 위해 색상 외 텍스트·아이콘·선 모양을 항상 함께 제공한다.
