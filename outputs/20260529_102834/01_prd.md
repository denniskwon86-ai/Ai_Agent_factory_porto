### 프로젝트명
OMEGA ERP V3.2

### 기능명
배터리 소재 공장 자재 소요량(MRP) 계산기 미니 대시보드

### 버전
V3.2 (기존 프로젝트 확장)

### 목표
*   배터리 소재 생산 계획에 필요한 자재 소요량(MRP)을 실시간으로 계산하고 시각화하여, 생산 관리자가 신속하고 정확한 의사결정을 내릴 수 있도록 지원.
*   기존 OMEGA ERP 시스템과의 연동을 통해 데이터 일관성 및 효율성 증대.

### 주요 기능
1.  **자재 소요량 계산 입력**:
    *   생산 목표량 (예: 특정 배터리 소재의 생산량) 입력 필드.
    *   생산 기간 (시작일/종료일) 선택.
    *   BOM(Bill of Materials) 데이터 연동 (기존 ERP 데이터 활용).
2.  **MRP 계산 및 결과 표시**:
    *   입력된 생산 목표량과 BOM을 기반으로 각 자재의 소요량 자동 계산.
    *   계산된 자재 소요량 목록 (자재명, 필요 수량, 단위).
3.  **미니 대시보드 시각화**:
    *   주요 자재별 소요량 현황 그래프 (예: 막대 그래프, 파이 차트).
    *   재고 현황과의 비교 (선택 사항, 기존 ERP 재고 데이터 연동 시).
    *   부족 자재 알림 또는 하이라이트 기능.
4.  **데이터 연동**:
    *   기존 OMEGA ERP의 BOM, 재고, 생산 계획 데이터와 FastAPI 백엔드 연동.
    *   계산 결과 저장 및 필요 시 내보내기 (CSV 등).

### 기술 스택
*   **백엔드**: FastAPI (Python)
*   **프론트엔드**: React (JavaScript/TypeScript)
*   **데이터베이스**: 기존 OMEGA ERP DB 연동 (예: PostgreSQL, Oracle 등)

### 대상 사용자
*   생산 계획 담당자
*   자재 구매 담당자
*   생산 관리자

### 성공 지표
*   MRP 계산 정확도 99% 이상 달성.
*   대시보드 로딩 시간 3초 이내.
*   사용자 만족도 설문조사 4점/5점 이상.
*   주간/월간 MRP 계산 및 분석 시간 20% 단축.
