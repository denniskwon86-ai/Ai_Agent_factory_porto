## 프로젝트 명
로컬 파일 기반 복구 세션 관리 도구

## 비즈니스 목적
사용자가 로컬 파일 시스템에 저장된 복구 세션 데이터를 쉽게 관리하고, 필요 시 신속하게 복구 작업을 수행할 수 있도록 지원합니다. 이를 통해 데이터 손실 위험을 줄이고, 사용자 경험을 향상시키며, IT 지원팀의 업무 부담을 경감시킵니다.

## 핵심 기능 명세
1.  **복구 세션 목록 조회 및 관리**:
    *   로컬 파일 시스템에 저장된 복구 세션 파일들을 자동으로 탐지하고 목록으로 표시합니다.
    *   각 복구 세션에 대한 정보 (이름, 생성일, 크기, 마지막 수정일 등)를 제공합니다.
    *   사용자는 복구 세션의 이름을 변경하거나, 삭제하는 기능을 수행할 수 있습니다.
    *   특정 복구 세션을 검색하거나 필터링하는 기능을 제공합니다.

2.  **복구 세션 생성 및 구성**:
    *   사용자가 복구할 파일 또는 폴더를 선택하여 새로운 복구 세션을 생성할 수 있습니다.
    *   복구 세션의 이름을 지정하고, 저장될 경로를 설정할 수 있습니다.
    *   복구 세션 생성 시, 백업 대상에 대한 압축 옵션 (예: ZIP, TAR.GZ) 및 암호화 옵션 (선택 사항)을 설정할 수 있습니다.

3.  **복구 세션 실행 및 복원**:
    *   선택된 복구 세션을 실행하여 지정된 경로로 데이터를 복원합니다.
    *   복원 시, 원본 위치에 덮어쓸지, 새로운 위치에 복원할지 등의 옵션을 제공합니다.
    *   복원 진행 상황을 실시간으로 표시하고, 완료 또는 실패 여부를 알림으로 제공합니다.
    *   복원 과정에서 발생할 수 있는 오류에 대한 상세 정보를 제공합니다.

## 제외 범위 (Out of Scope)
*   클라우드 스토리지 연동 (예: Google Drive, Dropbox, AWS S3)
*   네트워크를 통한 원격 복구 세션 관리
*   자동 백업 스케줄링 기능
*   복구 세션 파일의 무결성 검증 (체크섬 등)
*   복구 세션 파일의 버전 관리 기능
*   복구 세션 파일의 압축 해제 및 복원 외의 다른 파일 관리 기능 (예: 파일 편집, 이동 등)
*   운영체제 수준의 시스템 복구 기능 (예: OS 이미지 복원)
