### 프론트엔드 기술 요구사항

*   **프레임워크/라이브러리:** React (JavaScript/TypeScript)
*   **차트 라이브러리:** Chart.js 또는 Recharts
*   **주요 기능 구현:**
    *   MRP 결과 미니 대시보드 및 차트 시각화
    *   MRP 계산 트리거(버튼 등) 및 결과 조회/필터링 UI
    *   자재, BOM, 재고, 생산 계획 데이터 CRUD(생성, 조회, 수정, 삭제) 인터페이스
    *   데이터 유효성 검증 및 사용자 피드백 처리
*   **API 연동:** 백엔드의 RESTful API 엔드포인트(FastAPI)와 연동하여 데이터 송수신
*   **개발 언어:** TypeScript 활용 권장
