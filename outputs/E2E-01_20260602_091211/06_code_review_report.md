2.  **신규/수정된 API 엔드포인트 목록**
    *   **사용자 관리 (정의됨):**
        *   `POST /users`: 사용자 등록
        *   `GET /users/{user_id}`: 특정 사용자 조회
    *   **제품 관리 (정의됨):**
        *   `POST /products`: 제품 등록
        *   `GET /products/{product_id}`: 특정 제품 조회
    *   **BOM 관리 (정의됨):**
        *   `POST /boms`: BOM 정보 등록
        *   `GET /products/{product_id}/boms`: 특정 제품의 BOM 목록 조회

3.  **프론트엔드 주요 추가 컴포넌트**
    *   **메인 애플리케이션 진입점 (`index.html`):** 'Manufacturing Simulator' 웹 애플리케이션의 기본 HTML 구조.
    *   **애플리케이션 마운트 지점 (`<div id="app">`):** SPA 렌더링을 위한 핵심 요소.
    *   **메인 로직 로더 (`/src/main.ts`):** TypeScript 기반 애플리케이션 로직을 로드하는 스크립트 참조.
    *   **Vite 기반 프로젝트 설정:** 개발 환경 구성을 위한 초기 설정.
